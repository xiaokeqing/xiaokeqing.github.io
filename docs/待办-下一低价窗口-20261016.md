## ① 修 `/ai/` 冷缓存首屏超预算的风险（**先做这件**）

**现状（批次 A 交付时自己报的）**：`/ai/` 首屏 **1639KB / 预算 1650KB**，只差 11KB；
而她的头像图 `kurisu/avatar/normal.idle.webp`（86KB）在 `/ai/` 也是首屏可见元素。
现有 `_dev/gate-firstscreen.mjs` 按 **home→monitor→notes→ai→test 顺序 warm 跑**，
前四页把头像图带进了缓存 ⇒ `/ai/` 才没超。**冷缓存直接首访 `/ai/` 有可能 1639+86=1725KB > 1650KB。**

**怎么改（落点）**：`_dev/gen-demo-pages.py` 的 `IDCARD_PARTIAL`（头像是它的 `paint()` 取的）——
把"立刻 `im(url[D.emo])`"这一步改成：`/ai/`（`document.body.classList.contains('is-ai')`）时
`setTimeout(..., 1600)` 再取；其余页保持立刻取（站主点名的 UI 不能变慢）。
**改生成器 → 重跑生成器 → 重建**（不许只手改 `layouts/partials/xk-demo/idcard.html`）。

**验收（这条是硬要求：必须专门造冷缓存）**：

## ② P1-⑦ 主页底部对话输入栏第 1 期（接 `POST /api/public/ask`）

**门口闸门（规划侧新要求，与③同源）**：**未登录不渲染输入栏**；
一律走 `window.__xkAdmin`（批次 A 已埋好：`allowed()` / `fetch()`，未登录**直接拒、一个请求都不发**）。

**做法**：
```
1. 输入栏标记放主页（`<main id="content" data-xk-ssr="home">` 之外，与头像卡同层），默认 hidden
2. 显示条件 = `__xkAdmin.allowed()`（= 隐蔽入口已打开 或 有令牌）——访客 DOM 里连栏都不该出现
3. 提交（Enter / 按钮）→ POST `{apiBase}/api/public/ask`，body `{question}`（≤600 字符，与后端 maxQuestionChars 同口径）
4. 表情/动作**只按响应里的真实 `state` / `stateLabel`** 驱动（没有这两个字段就 `normal` + 只出字幕，绝不猜）
5. 🔊 默认关：语音只走统一播放器（批次 A 已把闸门收在 `playLine`），关着时**只出字幕**
6. 失败/超时/额度用尽 ⇒ **只出字幕 + 可读文案**（照后端原话：HTTP 码、Retry-After 倒计时、
   `quota.remaining`），不补"像答案"的文字、不刷屏报错
7. 不做 SSE / WebSocket（公开面只有一次性 POST）
```
**验收**：未登录时 DOM 里**搜不到**输入栏（含 `hidden` 之外的任何可见节点）；登录后真提问打通（截图）；
失败路径截图为证；console 0；首屏字节不变（栏在首屏窗口外才注入 / 或本身是纯 DOM 不请求）。
**顺带**：`/test/` 第⑨块（底部对话输入栏）翻绿（`test-lab.html` 可直接改）。

## ③ 登录按钮改走**后端令牌**（以 `docs/后端令牌登录与自用池设计-20261016.md` 为准）

> **★拆批口径见 §0.1**：本件分 **3a（现在做：无令牌不渲染 + 粘贴框 + 探针 + 失败文案）**
> 与 **3b（后端重建上线后才做：真实登录态 + 自用模式 + 自用池额度）**。
> **3b 之前不许出现任何"已登录"字样**（不假装已登录 ✗）。

**背景**：站主拍板**不做 Cloudflare Access**（不想绑卡），改走后端令牌；后端线已出设计定稿
（`feat/user-token-login` 分支，未合并未重建）。批次 A 现在的实现是**占位**：只判 `CF_Authorization`
Cookie 的存在性 ⇒ **必须改成令牌模型**。

**前端契约（照后端线 §2.1 逐字实现，不许自创）**：

| 项 | 约定 |
|---|---|
| 本地存放 | `localStorage['xk-user-token']`（**不写 Cookie**，避免被其他域/边缘缓存带走） |
| 请求头 | `X-User-Token: <令牌原文>`（新增独立头，不覆盖 `X-API-Token` / `Authorization`） |
| 登录态显示 | 有令牌 ⇒ 「**已登录 · 自用模式**」；**无令牌 ⇒ 按钮不渲染**（访客与"未粘贴令牌的站主"都看不到） |
| 按钮可见性 | 仍由 `sessionStorage['xk-admin-ui']=1`（隐蔽入口 `?admin=1` / `#admin` / 1.5s 内连点头像 5 次）控制 |
| 探针 | 存令牌后调 `GET /api/user/status` 确认；**401 ⇒「令牌无效，请重新粘贴」**；429 ⇒「尝试过于频繁，请 N 秒后再试」（N 取 `Retry-After`）；网络失败 ⇒ **不清** localStorage |
| 退出 | 点 👤 菜单「退出登录」= `localStorage.removeItem('xk-user-token')`，本地即可、不发请求 |
| 文案（逐字照抄后端线附录 B） | 未登录点 👤：「自用入口：请粘贴自用令牌（令牌只保存在本机浏览器）」<br>令牌无效：「令牌无效或已轮换 —— 请向站主要一份新的自用令牌」<br>登录面关闭（401 `USER_LOGIN_DISABLED`）：「自用入口当前未启用（服务端未配置令牌）」<br>软上限：「今日自用调用已达软上限 500 次，**仍可继续使用**（仅提醒，不限额）」 |

**红线（不改）**：**绝不硬编码任何令牌** ✗；令牌只留在站主自己的 `localStorage` ✗ 不进任何 `.js/.html/模板/构建产物`；
前端不把令牌发往 `xiaokeqing.cn` 以外的任何域。

**批次 A 已留好的接口（本件只需替换实现，不动结构）**：
`layouts/partials/xk-demo/idcard.html` 里的
`accessCookie()`（→ 改成 `userToken()` 读 localStorage）、`applyLogin()`（→ 改文案/图标）、
`login.addEventListener('click', ...)`（→ 改成弹出"粘贴令牌"输入 + `status` 探针 + 退出菜单）、
`window.__xkAdmin.allowed()/fetch()`（→ `fetch` 自动带 `X-User-Token` 头）。
**届时必须先建 `layouts/partials/xk-demo/idcard.html` 的生成器来源**（= `_dev/gen-demo-pages.py` 的 `IDCARD_PARTIAL`），再重跑。

**依赖**：后端线**重建上线后**才有 `/api/user/status` 可用。**顺序**：后端重建 → 前端换成令牌模型 →
联调一次（真令牌走通 + 假令牌 401 两条都要截图为证）。若后端还没上线，前端可先落"无令牌 ⇒ 不渲染 +
