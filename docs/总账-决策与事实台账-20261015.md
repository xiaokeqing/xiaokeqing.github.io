## 4. 事故与教训（避免重复踩）

```

⑦ Cloudflare API Token 无效（用户曾贴进聊天的那串返回 Invalid API Token / 9109）⇒ DNS-01 放弃、改手动；
   **凡在聊天里出现过的密钥都应到平台 Revoke 重建** ✗

⑫ .ps1 用编辑工具改会丢 UTF-8 BOM ⇒ PS5.1 按 GBK 读会假报语法错 ✗
```
