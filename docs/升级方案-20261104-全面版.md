# 项目升级方案（全面版）

> 2026-11-04。把前面几份分散的方案（`升级方案-20261030.md`、`栏目整理方案-20261104.md`、`页面设计稿-栏目整理-20261104.md`）合成一份可执行的总计划。
> 原则：**不加新功能、不动后端、不换技术栈、不删页面**；每一批都能独立上线、随时可回滚。

## 1. 现状体检（今天的真数字）

### 1.1 速度（3 Mbps 限速实测，本地构建产物）

| 页面 | 传输量 | 首屏 FCP | 加载完成 | 最大三笔 |
|---|---|---|---|---|
| `/` 首页 | **2054 KB** | 1176 ms | 3024 ms | `full/idle.boot.webp` **834 KB**、`opening.boot.webp` 275 KB、`video/idle1.webm` 119 KB |
| `/posts/` 笔记列表 | 930 KB | 820 ms | 1638 ms | `video/idle.webm` 115、`room_clean.webp` 76、`speaking_short.webm` 75 |
| `/posts/pki/` 笔记详情 | **518 KB** | 872 ms | 1531 ms | `room_clean.webp` 76、`manifest.json` 68、`xk-bind.js` 66 |
| `/categories/…` | 588 KB | **1432 ms** | 1767 ms | `bg-1920.webp` 136、`app.js` 119、`site.css` 77 |
| `/ai/` | 966 KB | 948 ms | 1629 ms | `video/idle.webm` 115、`room_clean` 76、`speaking_short` 75 |

**结论**：详情页已经瘦到 518 KB（原来 3.9 MB），**首页还有一块 834 KB 的 boot 图集是明摆着的浪费**（视频档 2 秒后就接管，boot 只是过渡帧）；分类页 FCP 1.4 s 偏慢，被 `app.js` + 大背景图拖住。

### 1.2 信息架构

- 站里 **17 个真页面**，导航只有 **10 个**，**7 个被埋**，而且被埋的恰好是最硬的：噪音指数 `/noise/`、IP 档案 `/ip/`、弱口令 `/passwords/`、样本分析 `/samples/`、红队榜 `/redteam/`、紫队 `/purpleteam/`、项目 `/projects/`。
- 导航里排着"状态""接口"这种运维内部页；"监测中心"是内部视角的词，访客想知道的是"现在被打成什么样"。
- 每个栏目地位相同、视觉语言两套（首页是 CRT 房间，内页是仪表盘），外人第一眼分不清"这站在讲什么"。

### 1.3 不痛的地方（不要动）

- 详情页结构、日报页、`/ai/` 交互、85 项断言、发布链路、慢网降档：都已验证过，**这次不碰**。
- 首页 CRT（电视 + 角色 + 语音）：**冻结**，一行不改。

## 2. 升级后要达到的三个效果

1. **10 秒看懂**：第一眼看到"这是一台被真实攻击的机器"，第二眼能找到"凭什么信"。
2. **硬东西浮出来**：噪音指数、IP 档案、红队榜这些最能证明能力的东西，两次点击内可达。
3. **像一个人做出来的产品**，不是一堆实验页：导航、页头、页脚、卡片全站统一。

## 3. 批次 P0：结构与速度（今天，约 3 小时）

### 3.1 导航从左侧挪到顶部（40 min）

- 高 56 px，磨砂半透明 `rgba(7,11,13,.72)` + `blur(12px)`，三段式：头像块 132 px ｜ 6 项居中 ｜ 右侧状态灯 + 时间。
- 首页**懒出现**：向下滚 80 px 后淡出到 0，鼠标回到顶部 60 px 内淡回——首屏仍是整屏电视，导航不抢戏。
- 手机端：这一条直接横向滚动，**删掉原来那套 dock CSS**（净减代码）。
- 头像 + 名字横向排（36 头像 / 两行字），把之前"96 px 挤不下、名字要不要放下面"的问题一次解决；`▾` 里的声音/设置改成下拉浮层。
- 高亮逻辑不变（`$v` 匹配）；三个断点验一遍。

### 3.2 导航 10 → 6 + 新建 `/more/`（60 min）

```
主页 · 攻击实况(/alerts/) · 安全日报(/daily/) · 攻防验证(/lab/) · 笔记(/posts/) · 更多(/more/)
```

（"监测中心→攻击实况""靶场→攻防验证"只是改标签，路由不变。）

`/more/` 是唯一新页面：12 张目录卡分四组（凭什么信这些数字 / 我练了什么 / 这台机器本身 / 顺手的小工具），卡片 = 标题 + 一句 description + 2~3 个小标签；3 列 → 2 列 → 1 列；**零 JS**。

### 3.3 13 个二级页加返回条（30 min）

`← 更多 / 分组名   同级：噪音指数 · IP 档案 · 样本分析`，36 px 高，整块可点回 `/more/#g-evidence`；手机端只留左半。

### 3.4 统一页脚（15 min）

`状态 ● 全部正常 · 端点清单 · 订阅 · 关于 · © 2026 XK-LAB`，三色状态取自 `/status/` 已有探测，不新增请求。

### 3.5 速度三刀（45 min）

| 动作 | 现状 | 做法 | 预计 |
|---|---|---|---|
| ① 首页 boot 图集 | `idle.boot.webp` **834 KB** | 视频档可行时，过渡期只用 poster 单帧（36 KB），boot 图集不进首屏 | 首页 **−800 KB**，load 3024→约 2300 ms |
| ② 内容页人物资源延后 | `manifest.json` 68 + `kurisu-player.js` 71 = 139 KB 首屏就拉 | 改成首个交互或 `requestIdleCallback` 后再取；内容页人物面板本来就折叠着 | 详情页 **−139 KB**，1531→约 1350 ms |
| ③ 分类页 | `bg-1920` 136 + `app.js` 119 | 背景按视口宽度选档（<1400 用 71 KB 版）；`app.js` 拆分，搜索模块等到点击搜索再加载 | 分类页 **−100~180 KB**，FCP 1432→约 1100 ms |

三刀合计：**首页 −800 KB / 详情页 −139 KB / 分类页 −150 KB**，且都不动首页 CRT。

### 3.6 收尾（30 min）

构建 → 85 项断言 → `publish-site-to-srv2.ps1 -FromRef HEAD` → 线上核对（6 个导航项、`/more/` 12 卡、返回条、页脚、旧 URL 全 200）→ 文档 §31。

## 4. 批次 P1：一致性（明天，约 2 小时）

1. **统一页头**：每个二级页顶部固定四件套——小标签（分组名）· 大标题 30px · 一句话导语 · 右侧状态灯/更新时间。现在各页各写一套。
2. **数字可点穿**：首页/日报上的 `152,011`、`94.9%`、`27` 这类数字，点了跳到算它的那页并定位到对应块（`/alerts/#severity`、`/noise/#ratio`、`/redteam/#cases`）。这是"可信"最便宜的证明。
3. **空态与降级统一文案**：拿不到数据一律写"读不到 + 原因"，绝不补 0（现在有的页写了、有的页没写全）。
4. **SEO 收口**：`/demo/` `/test/` 加 `noindex`；给 12 个二级页补 `description` 与 OG 图。

1. 1920 / 1280 / 1100 三档：导航一行放下，不换行、不横向滚动。

6. 3 Mbps：首页 ≤ 1300 KB、详情页 ≤ 400 KB、分类页 ≤ 450 KB，FCP 均 < 1.2 s。
7. 85 项断言全绿；17 个旧 URL 全 200；`/demo/ /test/` 已 noindex。
