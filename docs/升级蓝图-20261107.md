### 硬约定（踩过坑，别再破）

1. **`layouts/index.html` 与 `assets/js/xk-scene.js` 有两份同构的角色渲染代码**，改任何一份都必须同步另一份（首页走内联副本）。
2. **不能按设备分档，只能按实测网速分档**（站主明确口径）：`head-meta.html` 的 200 字节内联脚本给 `<html>` 挂 `class="xk-slow"`；`slow-2g/2g/3g`、`downlink<2`、`saveData` 为真才降档；`?xk-net=slow|fast` 可强制。
3. **Netlify 的 `/images/*` 缓存 30 天**：换图必须换 URL（`?v=YYYYMMDD`），否则用户浏览器永远看到旧图。
4. **播放器产物带 banner**：`assets/js/kurisu-player.src.js` 改完必须用 esbuild 重压并**保留 banner**（`static/js/kurisu-player.js`）。
5. **发布只发 HEAD 的干净 worktree**：未提交的改动不会进包，所以顺序永远是 改完 → 构建 → 断言 → commit → push → 发布。
6. **资产门禁 ⑨ = 256MiB**（角色+场景合计），超了断言会红；分片上限原声 64MiB / 合成 32MiB。
7. 新增公开端点必须**未登录 401**、响应统一 `{code,message,data}`、并进 `/api/public/kb` 的自描述清单。
8. 面向公网的 UI **不许出现未脱敏的完整 IP/口令/文件内容**（已有 `ipDisclosure`、`已脱敏` 口径）。

## 二、后端数据怎么"讲清楚"（信息设计）

### 2.1 现在的数据面

| 数据 | 来源 | 现状展示 |
|---|---|---|
| 24h 告警总数/分级 | `/api/public/alerts`（`stats24h`） | 三个大数字 + 一句"最凶来源" |
| 实时事件流 | 同上（5 分钟窗口聚合） | 等宽文本一行一条 |
| 国家/ASN 分布 | `/api/public/geo` | 右栏前 4 条 |
| 蜜罐捕获 | `/api/public/honeypot` | 右栏"用户/口令 7 位"+ 次数 |
| 封禁/拦截 | `/api/public/audit` | 累计数字 |
| 笔记/发布/断言 | 构建期快照 `data/ops_snapshot.json` | 首页数字卡 |
| 新：连接/端口/TLS | `/api/sec/conn/*`（需登录） | **尚未上页面** |

### 2.2 展示原则

1. **一个屏只回答一个问题**：`/alerts/` 回答"现在正被怎么打"；`/daily/` 回答"今天有多凶"；`/more/` 回答"这些数字凭什么可信"。
2. **每个数字都要能下钻**：数字 → 它由哪些事件算出 → 原始日志片段（已有 `stats24hReason` 口径，沿用）。
3. **宁可显示"取不到 + 原因"，也不编数**（站主口径，硬要求）。
4. **动画只在"有新事件"时发生**，不要常驻抖动。

### 2.3 具体可视化升级（含选型）

**V1 攻击地理（世界地图打点）**（1.5 天）
- 选型：**不引入重型图表库**，用 `world-atlas` 的 110m TopoJSON 简化到 ~40KB（或用现成 SVG 世界轮廓 12KB）+ Canvas 双层（底图 + 脉冲点）。
- 数据：`/api/public/geo` 的 `country` 计次；坐标用一张国家质心表（内置 ~200 行 JSON，15KB）。
- 交互：悬停国家显示"NL 107,929 次 / 5 个 IP"；点击过滤事件流。
- 验收：1440 下 60fps（`requestAnimationFrame` 采样 p95 < 20ms）；`prefers-reduced-motion` 下静态渲染。

**V2 24h 时序热力条**（0.5 天）
- 一行 24 格（每小时），颜色按告警强度；悬停出「该小时 top 规则」。
- 数据：`alerts?w=1440&bucket=hour`（若后端没有分桶，用现有 `stats24h.trend` 数组）。
- 验收：无数据的小时显示为灰色 `—`，不是 0。

**V3 分级环形 + 噪音漏斗**（0.5 天）
- 左侧环形：CRITICAL/HIGH/MEDIUM/LOW 占比；右侧漏斗：原始 29 万 → 去噪 94.9% → 真事件。
- 用纯 CSS `conic-gradient` + 少量 SVG，**不引库**。
- 验收：与 `/daily/` 的数字逐项一致（同一接口）。

**V4 端口/手法矩阵**（1 天，需登录后可见）
- 行=手法（SSH 爆破、MySQL 探测、HTTP 路径穿越…），列=目标端口；格子颜色=24h 次数。
- 数据：`/api/sec/conn/top-ports` + 告警规则号；脱敏口径同现有。
- 验收：登录态 200、匿名 401；格子点击 → 事件流过滤。

**V5 攻击链时间线**（1.5 天）
- 一个 IP 的「第一次出现 → 尝试 → 成功/失败 → 被封」横向时间线，节点可点开原始事件。
- 数据：`/api/public/by-ip` + `response/audit`。
- 验收：`193.32.162.20` 这类活跃 IP 能串出 ≥3 段；空链显示"只出现过 1 次"。

**V6 数字卡片统一"三个数字 + 一条口径"**（0.5 天）
- 所有卡片同一结构：`值 / 标签 / 口径一句话 / 下钻箭头`；不再出现"数字很大但看不出含义"。

> 技术约束：全部图表**自绘（Canvas/SVG/CSS）**，不引 ECharts/Chart.js —— 现在首页预算 1MB 内，引库会直接超标；已有断言会拦体积。
