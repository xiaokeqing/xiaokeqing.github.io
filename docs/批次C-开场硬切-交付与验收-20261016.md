## 一、现象与根因

| | 现象 | 证据 |
|---|---|---|
| 改前 | opening 播完后起一段 **900ms 的"推拉"**（`xkDrawTrans(k)`），满屏特写被**缩成一个小矩形贴在 CRT 中间**再融化淡出 | `_shots/batchC-before2-report.json`：剪影 502×378 → 450×332 → 334×252 → 262×198 → 234×176 → **210×158**（8 步连续缩小），随后才切 idle |
| 站主录屏 | 逐帧抽帧（`1918×1078 / 17.93s`）：特写占到 **10.0s**，**10.4s 已经是常驻** ⇒ 中间**没有**平滑缩放 | `E:\DeepSeek1\work\_bugshots\recdump\rec3_t10.png` / `rec3_t10p4.png` / `rec3_t10p8.png` |

**根因**：L1 那一版给 opening→idle 之间加了一段"过渡渲染"（`TRANS = performance.now()` + `xkDrawTrans(k)`），站主的录屏里根本没有这个过程。

## 二、改法与落点

- **不动** `T31_JS` 大字符串里的函数（三层转义 + 同一句在多个赋值点重复 ⇒ 上一窗口连试 6 版失败并回滚）。
- 改为在生成器 `_dev/gen-demo-pages.py` 里对**已经拼好的 `home_script` 文本**做三次**起止边界切片**（`find` 两端独特锚点、替换中间整段；任一端找不到就 `SystemExit`，绝不静默跳过）：
  1. `xkTransStart()`：`TRANS = performance.now()` ⇒ `TRANS = 1`（只立"该切了"的旗标，仍等 idle 位图就绪，避免切过去是空帧）；
  2. `drawFrame()`：`if(TRANS){ xkDrawTrans(...); return; }` ⇒ `if(TRANS){ return; }`（这一帧定格特写）；
  3. 主循环：`if(TRANS){ const k=… }` ⇒ `if(TRANS){ TRANS = 0; play('idle'); showHud(); }`（直接切 idle）。
- `xkDrawTrans()` 本体保留不删（改完已无调用点 ⇒ 行为就是硬切）；`public/index.html` 里 `xkDrawTrans` 命中数 **3 → 1**（只剩定义）。
- 生成器备份：`_dev/gen-demo-pages.py.keep-batchC-R2`。
