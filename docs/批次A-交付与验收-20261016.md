## 3. 首屏加载顺序 / 可交互时间 / 预取清单（站主追加②的验收件）

来源：`_dev/firstscreen-order.mjs`（CDP 真实网络，1280×900）→ `_shots/firstscreen-order-home.json`、`firstscreen-order.json`。

**主页（home）关键资源：**
```
资源                                        开始(ms)  完成(ms)  状态   字节
/images/crt/desk.webp     （壁纸·第 1 张）        24        34    200   77787

/kurisu/voice/bank.json                          1916      1919    200   12204
/kurisu/manifest.json        （空闲预取）          2056      2126    200       0（缓存命中）
/kurisu/video-manifest.json   （空闲预取）          2056      4262    200   20786
/kurisu/voice/bank.json       （空闲预取）          2056      4269    200   12204
```
* 页面自报的解码顺序 `window.__xkFirstPaint.order` = `glow@2ms → backplate@14ms → plate@31ms`（**串行、decode() 完才置位**）
* **首屏可交互**（导航栏入场 `#dock[data-xk-dock-in=flicker-end]`）= **845ms**；`domInteractive = 125ms`、`FCP = 188ms`、`loadEvent = 187ms`
* **空闲预取清单**（`window.__xkId.prefetch`）= `manifest.json@2058ms`、`video-manifest.json@2059ms`、`bank.json@2059ms`（都在 2000ms 之后）

> 口径说明：`desk.webp` 是**唯一** `fetchpriority=high` 的资源；其余按"出现顺序"由 JS 逐张 `decode()`，
> 高清图集 `opening.hi.webp`（1.0MB）被推到 1885ms（越过首屏 1.5s 门禁窗口）——这是既有的 boot→hi 两段式，本批未改其窗口。

## 5. 自主决定（站主不在，我拍的板 + 为什么）

| # | 决定 | 为什么 |
|---|---|---|
| 1 | 隐蔽入口**两个都做**（`?admin=1` 与"连点 5 次"） | URL 参数方便任意设备一步到位（可存书签）；连点 5 次零痕迹兜底"参数被猜到"。见 `docs/登录入口与自用模式-20261016.md` |
| 2 | 头像卡固定在**视口左上角 `left:0`**，并把既有 dock **下移到 `top:88px`** 给它让位（窄屏 dock 在底部 ⇒ 复位） | 站主字面要求"放到左上角"；dock 左中位置不变（只是整体下移），不做"第二个浮层抢导航"。改一行 CSS 即可回退 |
| 3 | 中文台词真源放**前端表**（`window.__xkLineZh`），**不改** `bank.json` 的 `text` | `bank.json` 是 TTS 管线产物（手改会被下次生成写回，违反"改生成物先改生成器"），且本批不重录音频 ⇒ 把"新字幕"集中在一张表里最好审、最好回滚 |
| 4 | 本批**不重录**日语音轨 | 重录要走本机 GPU 的 TTS 管线，不在 UI 批范围内；差异已在台词表里逐条标 ✅/否，下一批一次做完 |
| 5 | 内容页**本批还没有语音层** ⇒ 入口句只出字幕 | `kurisu-player.js` 与选句补丁属下一批（P1 ⑥）；本批如实只出字幕，**不假装念过**（`D.errors` 里记 `no-voice-layer`） |
| 6 | 修了两个自己踩的坑 | ① 头像图集是 8 列但只有前 3 帧有画面，按"列×行"算会画到空位 ⇒ 帧数取 3（清单到位后用真值覆盖）；② `.xk-idcard-btn{display:flex}` 会盖掉浏览器对 `[hidden]` 的 `display:none` ⇒ 登录按钮会漏给访客，补一条 `[hidden]{display:none}` |
