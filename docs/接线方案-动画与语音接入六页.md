## 1. 目标与验收口径

```

  ① 视觉对拍：接线上线前后，同视口同帧的**非角色区像素差 = 0**；角色区差异只来自更流畅的动画 ✓
```

## 3. 数据契约（字段级）

### 3.1 `static/kurisu/statemachine.json`
```jsonc
{
  "root": "idle",
  "node_count": 38, "edge_count": 88,            // [已实测] HEAD 584ecff 后为 38/88
  "nodes": [                                    // [已实测] nodes 是【数组】（38 元素），不是对象！
    {
      "id": "_8ms718k",                         // 节点 id ≠ 剪辑名；edges 靠 from_id/to_id 跳转
      "clip": "idle",                           // 对应 static/kurisu/medium/<clip>*.webp 或 video/<clip>.webm
      "frameIntervalMs": 17,                    // 单帧时长（帧间隔语义 ✗ 不是 fps）[契约]
      "loopMode": "loop | once_then_hold",      // 按剪辑计：loop 27 / once_then_hold 13
      "frame_size": [764, 1028],                // 几何在这：frame_size + 下面的 medium/hi.pages[]（节点【没有】geometry 字段）
      "medium": { "pages": [ { "url": "...", "file": "...", "tile_w": 134, "tile_h": 180, "cols": 8, "rows": 15, "frames": 60, "first_frame": 0, "last_frame": 59, "pixels": ..., "bytes": ... } ] },
      "hi": { "pages": [ ... ] },               // hi 档同结构（tile_w/h = 321/432）
      "atlas_source": "...", "tier": "...", "phase": ..., "opaque_bbox": ..., "incoming_prob_positive": ..., "is_root": false,
      "mouthPatch": { "closed_frame_idx": 0, "anchor_track": [...], "openness": ..., "preferredVariant": "patch|mask" },
      "has_mouth_profile": true
    }, ...
  ],
  "host_triggered_entries": ["angry_trans", "closed_eye_trans", "sad_trans", "shy_trans", "speaking_short", "speaking_trans", "surprise_trans", "thinking_trans", "trans_smile"],  // 9 个 = prob=0 边的全部目标 [已实测；T6 修复前只有 8 个、缺 thinking_trans]
  "clips_not_in_graph": ["sad", "smile"],       // [已实测] 有素材但不在状态机里
  "edges": [ { "from": "idle", "from_id": "_8ms718k", "to": "idle1", "to_id": "_8ms718l", "prob": 0.18 }, ... ]   // prob=0 ⇒ 宿主触发入口（9 条）；缺 from_id/to_id 无法跳转 [已实测]

```
**要点**：`prob=0` 的边**永不**被随机游走选中 ✓；出边概率需**归一化后**掷骰子 ✓；`once_then_hold` 停末帧 ✓。

### 3.2 语音 `bank.json`（`scripts/voice/build_bank.py` 产出）
```jsonc
{ "lines": [ {
  "id": "greet_first", "trigger": "greeting", "emotion": "shy",
  "ja": "おかえりなさい。…", "zh": "欢迎回来。…",
  "audio": "voice/greet_first.m4a",
  "audioSources": { "m4a": "voice/greet_first.m4a", "webm": "voice/greet_first.webm" },
  "envelope": { "sampleRate": 8000, "hopMs": 10, "values": [0.12, …] },
  "durationMs": 9530, "sha256": { "m4a": "…", "webm": "…" },
  "source": "live|new" } ] }
```
**要点**：`envelope` **必须从最终分发的编码文件重算** ✗（母带重算会与听觉不一致）`[已实测：与线上 12 句逐点 100% 一致]`。

### 3.3 口型映射
```
mouthValue(t) = clamp( envelope.values[floor((t_ms - t0_ms)/10)] * 3.75 , 0, 1 )
静音阈值 0.08（**不写进包络** ✓）｜说话首窗保底 0.12｜停止后 3 个窗内衰减到 0
闭嘴层：mouthValue ≤ 0.08 时按 mouthPatch 叠加（12 个剪辑用小补丁；4 个用原方案=截块+椭圆遮罩）
```

## 4. 模块设计（接口级）

### 4.1 `xk-voice.js`
```js
export function initVoice({ bankUrl, onMouth, onSubtitle, onState }) → {
  unlock(): Promise<void>,     // 首次手势调用；失败的 Promise 只 log 不抛
  isUnlocked(): boolean,
  speak(lineId, { force } ): Promise<void>, // 已解锁才播；同 id 300ms 内去重
  stop(): void,
  mouthValue(): number,        // 由 rAF 从 <audio>.currentTime 查包络，缓存在闭包
  on(event, fn): void          // 'unlock' | 'end' | 'error'
}
行为契约：
  · 手势前任何调用都**不入队播放** ✗，只记录 "pending"（解锁后补放最近一条，最多补 1 条）
  · 播放失败（404/402/decode）→ 触发 'error' → 页面走"只显示字幕" ✓，**不弹任何错误 UI** ✗
  · 页面 hidden → pause()；visible → 从暂停点续播（不重头 ✗）
  · 音量/语速：语速不支持在播放端改（会破坏包络对齐 ✗）→ 需要改就在生成端调 ✓
```
**触发规则**（`trigger → 时机`）：
```
greeting    首访/回访分流（localStorage 标记，回访用回访台词）｜首屏加载后 1.5s 且已解锁才播
page_intro  每页进入时一条（六页各一条）｜同页 10 分钟内不重复
status      状态行**真实文本发生变化**时（不是定时器 ✗）｜20s 防抖
event       新告警/新故事线（同一事件 id 去重）｜优先级最高，可打断 status
idle_banter 无操作 >90s 且页面可见
fallback    接口取不到数据时（与"读不到"文案同时出现）
emotion     点击她 / 事件严重度变化
```

### 4.2 `xk-clip-video.js`
```js
export function createClipRenderer({ mode /* 'video'|'pixel' */, canvas }) → {
  ensure(clipName): Promise<void>,   // 视频：preload=auto → loadeddata；图集：<img> decode
  draw(clipName, frameIndex, rect): void,
  duration(clipName): number,        // ms，来自 statemachine.frameIntervalMs × 帧数
  dispose(clipName): void,
  stats(): { videos, imgs, bytesHint }
}
行为契约：
  · <video> **不进 DOM**（离屏 + muted + playsinline），避免任何样式/层叠影响 ✗
  · 同时存活的 <video> ≤ **4**（超了就 dispose 最久未用者；6GB/低端机上解码器有限）[风险]
  · 硬切：两枚 video 交替（A 播完在 B 上 seek(0) 并 play，下一帧起画 B）→ 避免 seek 白屏
  · 首帧：先画 `poster.webp`，`loadeddata` 后再画视频（**任何情况下不留空框** ✓）
  · 解码失败/`video.error` → 该剪辑**永久降级**到 pixel 路径（不再重试 ✗，避免每帧报错）
```

### 4.3 `xk-graph-walker.js`
```js
export function createWalker({ graph, renderer, voice, mouth, rng }) → {
  start(): void, stop(): void,
  trigger(kind, payload): void,      // 'voice' | 'emotion' | 'idle' | 'cadence' | 'host'
  current(): string,
  timeline(): Array<{ t, node, reason }>   // = 旧 __xkSm.hostTimeline 的等价物，用于 replay 与验收
}
行为契约：
  · 纯概率游走只能覆盖 10/38 个剪辑 `[已实测]` ⇒ 必须实现**宿主触发**入口（否则"她只会发呆" ✗）
  · `cadence` 是兜底：连续 >25s 没有任何宿主事件 → 走一次 idle 类节点（防止长时间凝固 ✗）
  · 每次切换记 `reason`（`auto:<edge>` / `host:<kind>`），验收时按 reason 统计 ✓
  · 支持 `?seed=<n>`（可复现）与 `?replay=<base64>`（按 timeline 回放同一段画面，用于截图对峙 ✓）
```

## 5. 时序（文字版）

```
页面加载
  ├─ 立即：画 poster 静帧（不阻塞首屏 ✓）；解析 statemachine.json（若 >50KB 则 idle 时异步解析 ✓）
  ├─ 用户第一次 pointerdown/keydown
  │     └─ voice.unlock() → 补放 pending 台词（≤1 条）→ 允许视频预载 ✓
  ├─ 无手势但有 IntersectionObserver 进入视口
  │     └─ 允许**图集**预载（image 不需要手势 ✓），**视频不预载** ✗
  └─ walker.start()
        ├─ auto 边：播完 → 归一化掷骰子 → 下一个节点
        ├─ host 边：voice/emotion/idle 事件 → 直接切（打断当前 once_then_hold 的剩余部分 ✓）
        └─ 每帧：renderer.draw(clip, idx, rect) + mouth.apply(mouthValue())
页面 hidden → 暂停 walker ticker / video / audio，**清零时间累加器**（否则切回快进 ✗）
页面 visible → 从当前帧继续；音频从暂停点续播
```

## 6. 加载与预载策略（分级）

| 情形 | 图集 | 视频 | 语音 |
|---|---|---|---|
| 首屏（未交互） | 只载 **current + 出边 top-2** | **不载** ✗ | 不载 |
| 首次交互后 | 按需 | 载 **root→idle→出边 top-2**，其余按需 | 载当前页所需 1 条 + 预取下一条 |
| `navigator.connection.saveData` 或 `effectiveType ∈ {2g,slow-2g}` | 按需 | **只用 poster 静帧**（不载视频 ✗） | 只载将要播的那条 |
| `deviceMemory ≤ 4` 或 屏幕 <980px | 按需 | 只载 idle+opening | 同普通 |
| `prefers-reduced-motion: reduce` | 只载 idle 首帧 | 不载 | 不自动播（按钮仍在，点了才播 ✓） |

**字节预算**（对应门禁 ≤1650KB/页）：首屏"图集 current + 出边 top-2 + poster + 页面自身"应 ≤ **700KB**。但注意：**首屏大头是 `opening.hi.webp`（1,004 KB，占主页 1569KB 的 65%）**——视频接线对首屏**零帮助** ✗；要降首屏必须做两段式（boot 档先上、hi 延迟，见 T5.6）。`[已实测] 2026-10-15 T5.6 实施后：主页 840KB、四内容页 185KB、/ai/ 1555KB`

## 7. 口型层实现细节

```
① 每帧取 mouthValue（来自 voice.mouthValue()；无语音时 0）
② 若 ≤0.08 且该剪辑有 mouthPatch：
     variant=patch → drawImage(mouth/<clip>.closed.webp, 目标矩形 = anchor_track[frameIdx] ± 半宽高)
     variant=mask  → 从当前帧 drawImage 截取嘴部矩形 → 再 fill 椭圆遮罩（原方案，抗锯齿更自然）
③ 逐帧锚点：**不要**用固定坐标 ✗（头在动）；anchor_track 缺帧 → 用最近帧线性插值
④ 与视频叠加顺序：video/canvas → 闭嘴层 → CRT 扫描线/暗角（保持 CRT 效果在角色之上 ✓）
⑤ 说话段不叠 ✓；`speaking_*` 剪辑自身的嘴在动，叠加会双重运动 ✗
```

## 8. 降级矩阵（能力 × 行为）

| 失效点 | 检测方式 | 行为 |
|---|---|---|
| 视频解码不支持 alpha | 首次 `drawImage` 后采样四角 alpha（品红底法 `[已实测]`） | 该剪辑降级图集；全局二次失败 → 全站 pixel |
| 视频 404/网络断 | `video.error` / `fetch` 失败 | 降级图集 → poster |
| 图集缺页 | `<img>.onerror` | poster 静帧（仍能硬切） |
| 音频 404/解码失败 | `<audio>.error` | 只显示字幕 ✓ |
| 麦克风/权限 | 本方案**不使用**麦克风 ✗ | — |
| 状态机 JSON 解析失败 | try/catch | 回落到"原型 4 剪辑小循环"（即**保持现状** ✓，绝不能白屏 ✗） |
| 接口挂 | fetch 非 2xx | 数字写"读不到" + 播 `fallback` 台词 |
| 页面隐藏/切回 | visibilitychange | 暂停 + 清零累加器，回来续播 |

## 12. 风险清单（按概率×影响排序）

```
[风险] ① Safari 的 VP9-alpha 支持未验证 → 影响 iPhone 访客"她"会变成 poster 静帧 ✗
       对策：先探测（品红法），失败则 iPhone 走图集路径；`[待核对]` 是否值得为 Safari 出 B3(色/A 双拼) 兜底
[风险] ② 6 枚以上 <video> 同时存活 → 解码器/内存吃紧（6GB 机上尤其）
       对策：硬上限 4 枚 + LRU；`[风险]` 高刷屏 120Hz 下 rAF 频率高，注意每帧只做一次 drawImage
[风险] ③ 状态机概率游走导致"她长时间卡在 idle 变体"（观感呆滞）
       对策：`cadence` 兜底 + 宿主触发（voice/status/emotion）提高下限；验收里已列为可测项
[风险] ④ 语音 60 句超预算 4.5% → 影响首屏预算；对策：只发 8~12 句样本，或降到 40k/32k
[风险] ⑤ 每帧 drawImage + 合成在低端机上掉帧（尤其中景 268×360 ×2 倍缩放）
       对策：`devicePixelRatio` 上限 2；低端降 m134 档视频（已有开关 ✓）
[风险] ⑥ 原型五页那条 TypeError 仍在 ✗ → 接线时若复用它的 scene-js，异常会连带影响角色层
       对策：接线时先修那条依赖（或让角色层独立于 scene-js 生命周期 ✓）
[风险] ⑦ 音频与动画的时钟不同源（audio.currentTime vs performance.now）
       对策：以 audio 为主时钟驱动 mouthValue；动画按自己的 ticker 走，两者只在"说话开始/结束"同步
[风险] ⑧ 预载与门禁冲突：首屏预载 top-2 可能把 ai 页（当前 1637KB）顶过预算
       对策：ai 页首屏只预载 current，top-2 延到首次交互后 ✓
```
