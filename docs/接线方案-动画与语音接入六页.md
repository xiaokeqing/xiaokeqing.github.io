# 接线方案 · 把「状态机 + 视频 + 语音 + 口型」接进六页

> 本文是**唯一一份"怎么把已有的东西挂进页面"的施工规格**。前置成果都已就绪，本文只讲接线。
> 现状：六页 = 设计原型整份 + 真实数据（已上线 srv2）；她的动画目前用的是**原型自带的那段 4 剪辑小循环** ✗，
> 我们自己的（38 节点状态机 / 9.54MB 视频 / 桐莉栖日语语音 / 嘴部补丁）**都还没接** ✓

## 0. 硬约束（违反即回滚）

```
① **视觉不变**：原型那份版式/配色/层次/几何一个字不改（用户验收标准 = 看着像作者想给的效果）✗
   允许新增的只有"看不见的东西"：加载逻辑、事件绑定、canvas 绘制来源、feature flag
② 三道门禁必须绿：`scripts/assert-build.sh`（资产 ≤80MiB）｜`_dev/gate-firstscreen.mjs`（六页首屏 ≤1650KB）｜
   `_dev/check-ssr-contract.py`（6/6）
③ 站点红线：零第三方请求 ✗ ｜数字只来自真实接口 ✗ ｜CSS 加容器前缀 ✗
④ 现有契约不许破：`Math.max(16, frameIntervalMs)` 夹取（图集回退路径）｜`once_then_hold` 停末帧｜
   `visibilitychange` 暂停 ticker **并清零时间累加器**｜reduced-motion / saveData 降级｜
   **没有任何音频在用户手势之前播放** ✗
⑤ 发布：`push` ≠ 上线 ✗ —— 必须再跑 `scripts/publish-site-to-srv2.ps1`（srv2 原子切换）
```

## 2. 第一步：语音接线（1~2 小时，风险最低，成果最直接）

**新增一个模块**（例如 `static/js/xk-voice.js`，从 `kurisu-player.js` 抽语音/包络那部分，约 150~200 行）：

```
职责：
  ① 加载 `static/kurisu/voice/bank.json`（懒加载，首屏不载 ✗）
  ② autoplay 门控：`unlocked=false` 时**不播**；页面上放一个"🔊 点我开声"按钮（位置照现有 UI 风格，
     不新增原型里没有的大块元素 ✗）；首次 pointerdown/keydown → 解锁 AudioContext → 补放最近一句
  ③ 触发：`greeting`（首访/回访，localStorage 标记）/ `page_intro`（每页一条）/
     `status`（状态行真实文本变化时）/ `event`（新告警/故事线）/ 点击她 → `emotion` 类
  ④ 字幕联动：播放谁就显示谁的 `zh`（写进原型已有的字幕元素 ✓，**不新增元素** ✗）
  ⑤ 包络：`<audio>` 播放时按 `currentTime` 查 10ms 包络 → 暴露 `mouthValue`（给第三步用）
  ⑥ 降级：没音频（402/404/解码失败）→ 只显示字幕 ✓；`prefers-reduced-motion` 或 `saveData` → 不预载音频 ✓
```

**验收**：手势前 `unlocked=false / plays=0` 且按钮文案是"点我开声"；手势后 `plays=1`、字幕与音频同步、
控制台 0 报错；六页首屏字节不超标 ✓

## 3. 第二步：视频接线（2~3 小时）

**把"从 PNG 图集逐帧画"换成"从 <video> 画"**，并保留图集回退：

```
新增模块（例如 `static/js/xk-clip-video.js`）：
  ① 每个剪辑一条**离屏** `<video muted playsinline preload="none">`（不进 DOM，天然不碰 CSS 前缀纪律 ✗）
  ② `ensureClip(name)`：首次需要时 `preload="auto"` → `loadeddata` 后 `drawImage(video, …)` 画进现有 canvas
  ③ 预载纪律：只预载 **root → idle → 高频出边 top-2**（graph-walker 知道出边概率 ✓）；
     其余一律按需；**首次用户手势之前不预载视频** ✗
  ④ 回退顺序：视频不可用/解码失败/`prefers-reduced-motion`/`saveData`/窄屏低配 → 用 `static/kurisu/medium/*` 图集；
     图集也缺 → 用 `<clip>.poster.webp` 静帧
  ⑤ 硬切：`once_then_hold` = 播完 `pause()` 停末帧 ✓；节点间硬切时用两个 <video> 交换可见性（避免解码延迟白屏 ✗）
  ⑥ 帧时长：视频是 VFR（逐帧时长 = 各剪辑 `frameIntervalMs` 8/17/21ms ✓）—— **不要**再用 rAF 网格推帧
```

**验收**：30 秒内 ≥8 个不同帧指纹 ✓；与 PNG 路径同屏同帧比对（alpha 边缘 NCC ≥0.99 ✓）；
首屏仍 ≤1650KB ✓；`Safari` 无 alpha 时落到 poster（如实标注未在 Safari 实测 ✗）

## 4. 第三步：状态机 + 口型接线（3~5 小时，最难）

```
① 把原型那段"4 剪辑小循环"替换为 **graph-walker**：
   · 读 `static/kurisu/statemachine.json`；root=idle；每段播完按**出边概率归一化后**掷骰子
   · `prob=0` 的 9 条边 = **宿主触发入口**，只由事件走（voice / emotion / idle>12s / cadence 兜底）
   · `once_then_hold` 12 个剪辑：播一遍停末帧再换节点
   · 调试：支持 `?seed=<n>` 与"录制回放"（把节点序列存下来复现同一段画面 ✓）
② 口型层：拿第一步的 `mouthValue` → `≤0.08` 时把**闭嘴补丁**按 `mouthPatch` 的坐标/遮罩叠到角色帧上
   · 12 个剪辑用小补丁 ✓；4 个用原方案（截块+椭圆遮罩）✓（按数据里的 `preferredVariant` 选）
   · **逐帧对位**（头在动，锚点每帧变）✓；不要把补丁位置写死 ✗
③ 窗口尺寸变化：按落位公式重算，并处理 devicePixelRatio（避免二次插值发虚 ✗）
④ 页面隐藏：暂停 ticker + 视频 + 音频，**清零时间累加器**（否则切回会快进 ✗）
```

**验收**：30 秒游走序列落在合理分布内（不是只在 idle 变体里打转 ✗——纯概率游走只覆盖 9/38 个剪辑，
必须能看到 voice/emotion/idle 三类宿主触发真的发生 ✓）；说话段与静音段的嘴部对照截图 ✓

## 6. Feature flag 与回退（必须做，别裸奔 ✗）

```
· 一个总开关：`<html data-xk-kurisu-mode="pixel | video | off">`（默认 `video`，`off` = 完全停在原型静态行为）
· 每级独立降级：video → pixel(图集) → poster(静帧) → 不动（原型原样）
· 一键下线：`kurisuEnabled=false` 时**整个角色层不加载**（站点回到纯文本版 ✓ —— 这是既有红线，不许破）
```

## 7. 已踩过的坑（接线时重点防）

```
① 视频 alpha：**只能 VP9+alpha**（AV1+alpha 在 Chromium 解不出透明，实测 0.0%）；容器必须 WebM（IVF 无浏览器支持 ✗）
② WebM 加不了 `+faststart`（matroska 无该选项）—— 但索引天生前置（实测 SeekHead@48B/Cues@102B）✓
③ 色彩标记要在 `-i` 之前也写，否则 libvpx-vp9 会把它覆盖回 unknown ✗
④ 素材包 `clip.json` 的 `layout` 有 2 组写错（1027 vs 实际 1028）→ 一律以实际码流尺寸为准 ✗
⑤ 新包帧是 0.738× 居中裁窄的 → 转码前必须 `pad=764:1028:100:0:black`，否则角色横向跳 9.5% ✗
⑥ staging 图集工具读的是缓存 `recon.json` → 新增剪辑要先刷 recon ✗
⑦ 本机 ffmpeg 子进程往博客仓库目录写会 **EACCES** ✗ → 产物一律落仓库外
⑧ 音频**只写文件不播放**（本站曾被误以为在自动出声 ✗）；页面里也绝不在手势前出声 ✗
⑨ 本机直连线上 443 会被 **SNI 过滤重置** ✗ → 验证走 `ssh secagent-srv1` 侧，或本地 `public/` 产物
⑩ `.ps1` 用编辑工具改会丢 BOM → PS5.1 按 GBK 读会假报语法错 ✗
```
