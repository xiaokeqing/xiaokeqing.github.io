## 二、逐项证据

### V1 电视只演高清剪辑（质量闸 268px）
- 代码：`_dev/gen-demo-pages.py` 的 `xkFw(nodeId)` + `entryFor`/`roll` 里的 `if(xkFw(x) && xkFw(x) < 268) continue;`
- 实测（本地 8766）：`__xkSM.stats()` → `tookOver:true`、`cur:"idle1"`、`recent` 连续 4 步 `frame 268×360`
- 断言：`scripts/assert-build.sh` 里"只演 ≥268px"

### V2 / V2b 手机 E-mote
- 代码：`static/js/phone-emote.js`（`mount/setMode/setExpression/expressionLabels`）、生成器 `XK_EMOTE_BOOT_JS`
- 门槛：`innerWidth≥1280`、`deviceMemory≥8`（有上报时）、`cores≥4`、非主页、`!window.__xkPhoneEmoteOff`
- 实测：`__xkPhoneEmoteInst.status()` → `state:"ready"`、`loadMs≈1300–1400`、`gpu:true`、`expressions:28`
- `fps` 口径修正：`measureFps()` 改为挂载后 1.5s 再测 ⇒ 171（页面 rAF 稳态量级），此前报 2 是与初始化重叠

### V3 极弱网省流
- 代码：`static/js/xk-saver.js`（触发 `saveData` / `effectiveType ∈ {slow-2g,2g}` / `?xk-saver=1`）
- 拦截：`HTMLImageElement.prototype.src`、`Element.prototype.setAttribute`、`HTMLScriptElement.prototype.src`、
  `fetch`/`XHR` 拦 `manifest|video-manifest|voice/bank.json`、`requestIdleCallback` 置空
- 实测（8766 `?xk-saver=1`）：`__xkSaver===true`、`html.xk-saver`、`smOn:false`（状态机不起）、
  网络里只剩 HTML + `xk-saver.js` + 底图三张 + favicon；`data:text/javascript,` 证明播放器被拦
