## 口径与限制

- 来源 IP 只取日志里的 `src_ip`；Dionaea 用 SQLite 的 accept 连接与 logins 关联，避免和 dionaea.json 重复计数。
- 独立规则按 Suricata `signature_id` 去重；本仓库的 xk-lab 规则未部署，因此这里反映的是线上 ET 规则命中。
- 端口跨度按“去重后的目的服务端口数”计分；`port_span` 另列 max-min+1 供核对。
- 心跳（10.0.0.10 → 169.254.0.4:80）与 RFC1918 内部源自噪声直接 0 分，但保留原始计数。
- 自有资产 srv1 `47.96.106.187`、srv2 `43.143.114.79` 用 `--self-ip` 记 0 分，避免把自家扫描当外部威胁。
- 时间窗口由日志本身决定，不裁剪；封禁名单按历史记录计，不区分是否已过期。
- 封禁名单本次按 2026-10-17 已记录的 7 个 IP 以 `--ban-ip` 传入；srv1 的 `blocked-ips.json` 归 `systemd-coredump` 所有且当前账号无 `CAP_DAC_OVERRIDE`，未能重新读取原文。
