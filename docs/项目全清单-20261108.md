```
├─ scripts/        构建断言、快照刷新、发布、日报/周报/月报、各类审计（含子目录 cve/eval/geo/kurisu/noise/redteam/voice）

└─ .github/workflows/  deploy.yml（构建+断言+gh-pages 跳转页）、snapshot.yml（*/10 快照）
```

**最容易改错的三处**：

1. **`layouts/index.html` 里有一份与 `assets/js/xk-scene.js` 同构的角色渲染**（内联 `CLIPS`/`CHAR_BOX`/`draw`/`drawFrame`/`hiAtlas`/`paintHi`/`paintOps`，分别在 398/405/706/814/1381/1421/1438 行）。只改 JS 不改首页内联副本，会出现"首页角色正常、其他页角色错位"或反之。改任何一处必须两处同改。
2. **`static/api/public/` 会被 `.gitignore` 的 `public/` 规则吃掉**。快照脚本必须 `git add -f static/api/public`；手工提交漏 `-f` 会导致线上快照永远是旧的。
3. **`assets/` 与 `static/js/` 是两套加载路径**：`assets/` 走 Hugo Pipes（压缩+指纹，产物在 `public/js/*.min.<hash>.js`），`static/js/` 原样拷贝、无指纹。新写 JS 若图省事丢进 `static/js/`，会失去缓存失效能力（改内容 URL 不变，浏览器/CF 继续用旧文件）。

> 数据来源：目录列举、`layouts/index.html` 行号 grep、`scripts/snapshot-refresh.ps1:31`（`git add -f`）、`layouts/partials/xk-demo/shell-script.html` 的 Pipes 调用。

公开池：6 次/分钟/IP + 同源并发 1 + 30 次/日；带 `X-User-Token` 的站主请求跳过限流（响应头 `X-Owner-Ask: 1`）。

流程：0 环境检查 → 1 找 hugo → 2 从 git ref 拉临时 worktree + 构建 + `asset-version.py` → 3 产物校验 → 4 打包（临时目录优先 `E:\DeepSeek1\work\_pubtmp`）→ 5 scp 到 srv2 `/home/ubuntu/.xk-deploy/` + 同步接收脚本 → 6 远端 `srv2-site-receive.sh` 解包/校验/`releases/site-*` 原子切换/自检 → 6.5 把 `release-info.json` 同步到 srv1 `/opt/secagent/data/public-api/` → CF purge（失败只告警）。

**五道核对闸门**：

| # | 闸门 | 失败判据 |
|---|---|---|
| 1 | 构建源：目标 ref 可解析、worktree 干净 | 解析失败/脏树直接退出 |
| 2 | 产物特征：`index.html` 存在且 ≥ 3000 B（2026-11-04 首页改门页后从 4096 降） | 缺文件/过小即拒 |
| 3 | **自动跑 `assert-build.sh` 90 项** | 任一失败即拒，连 tar 都不打 |
| 4 | 整树内容哈希 vs 线上（忽略 `index.json` 的 generatedAt、`manifest.json` 的远端生成） | 不一致才上传；`-DryRun` 可预览 |
| 5 | 远端接收 `RESULT=ok` 或 `no-change`，并跑接收侧自检 | 其他值视为失败，保留旧 release |

**已知坑**：① 必须用 Git Bash，且 PATH 剔除 `WindowsApps`；② 临时目录别放 C 盘（C 盘曾只剩 2.4 GB，出现"tar 里没有 index.html"的假失败）；③ PowerShell 把 stderr 当错误，脚本"成功却 exit 1"多为 `2>&1 | Select-Object` 造成，用 `*> 日志`；④ 不要落 `/tmp`，腾讯云主机安全会误报；⑤ 接收侧文件数比发送侧多 1（它把 `index.json` 算进去），属正常。

**回滚**：远端保留 `releases/site-<时间戳>/`，把 `current` 符号链接切回上一版并 reload nginx；`release-info.json` 同步回退。回滚不需要重新构建。

### 8.2 后端链：`scripts/deploy-remote-build.ps1`（16,837 B，位于 sec-agent 仓库）

官方链路：commit → `build-image.yml` 构建带 OCI label 的镜像 → push ACR `:stable` → srv1 `srv1-redeploy.sh --expect-commit <sha>`。
手工兜底：bundle → srv1 fetch → checkout → `deploy-remote-build.ps1 -TargetSha <sha>`（旧参数名 `-TargetCommit`）。

**五道核对闸门（fail-closed）**：

| # | 闸门 | 失败表现 |
|---|---|---|
| 1 | 本机：git 工作区、HEAD == 目标 commit、工作区状态 | 不 clean 则拒绝/提示 |
| 2 | 本机：`mvn package` 后从 fat jar `BOOT-INF/classes/git.properties` 读 commit/dirty 核对 | 不符连 scp 都不做 |
| 3 | 服务器：源码树 clean + HEAD == 目标 | exit 6/7 |
| 4 | 服务器：镜像内 jar 的 MD5 与上传件硬校验 | exit 8 |
| 5 | 部署后：轮询 `/api/health`（120 s，每 3 s），要求 `status=ok` 且 `embeddedGitCommit == 目标 sha` | 超时打印全量 JSON |

**已知坑**：① `secagent-redeploy.timer` 每 5 分钟按 ACR `:stable` digest 对齐，会把手动部署"回滚"掉——脚本只警告不自动停；② `SPRING_APPLICATION_JSON` 的空默认值会覆盖环境变量（曾导致封禁白名单变成 0）；③ 别用多阶段 Dockerfile，运行时镜像由 `Dockerfile.runtime` + `build-on-server.sh` 组装；④ 目标是"可回滚"：ACR 保留上一 digest，回滚=把 `:stable` 指回旧 digest 再跑 redeploy。

## 10. 必须遵守的约定

违反任意一条，通常不是"样式不对"，而是**发布失败或线上直接坏**。

1. **不引第三方图表库**。所有图表是手写 canvas/CSS（`xk-viz.js` 2,779 B 构建后）。首页首屏预算已被压到 ~751 KB，引一个 Chart.js 就破。
2. **任何新 JS 必须走 Hugo Pipes 指纹化**（放 `assets/js/`，用 `resources.Get | minify | fingerprint`）。放 `static/js/` 会失去内容哈希，改完用户仍拿旧缓存；`static/js/` 现有文件是历史例外（播放器、phone-emote 等），不要扩大。
3. **改 `assets/js/xk-scene.js` 必须同改 `layouts/index.html` 内联副本**（反之亦然）。两份是手工同构的，没有构建期校验，只有断言能间接发现几何差异。
4. **产物里禁止出现 `localhost` 字样**（断言第 ⑤ 类）。本地调试地址写进模板会导致发布被拒；用 `127.0.0.1` 也会被同规则拦。
5. **HTML 多行标签不能按行删**。Hugo 模板里的 `<a ...>` 跨行属性，按行编辑容易留下半个标签；改结构用整块替换。
6. **`static/api/public` 被 `.gitignore` 的 `public/` 规则吃掉**。提交快照必须 `git add -f static/api/public`；`snapshot-refresh.ps1:31` 已带 `-f`，手写命令别漏。
7. **PowerShell 没有 heredoc**。多行 bash 脚本不能直接塞进 `ssh "..."`；写成 `.sh` 再 `scp` 过去执行，或用 here-string 落临时文件。
8. **Hugo minify 会改函数名**。部署标记/健康检查不要依赖 JS 函数名（会被压成单字母）；用中文字符串或固定 `data-*` 属性做标记。
9. **`data/ops_snapshot.json` 必须用下划线**（不是 `ops-snapshot.json`）。取不到数据时保留旧快照并标注，不要写"未取到"占位——页面会把它当数字渲染。
10. **资产总量上限 256 MiB**（原声 64 MB + 合成 32 MB 分片）。新增图集/语音前先算总量，断言第 ⑨ 类会直接拒发布。
