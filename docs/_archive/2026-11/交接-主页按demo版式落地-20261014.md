## 三、如实写：剩下的 3.0% 是什么，以及三处"必须知道"的事实

1. **demo 原文件缺素材**：`docs/demo-assets/` 里**没有 `opening.hi.webp`**（只有 `opening.boot.webp`，26 个文件，
   不是计划里写的 34 个）。demo 主页的 `CLIPS.opening` 指向它 → **demo 自己渲染时开场永远画不出来、
   canvas 全黑、HUD 永远 hidden**。做像素对比时我在**对比副本**（`_dev/pixel-demo-home.html`）里把它指到
   `/kurisu/full/opening.hi.webp`，否则比出来的数字没有意义（第一版就是 99.97%）。
   这一条**不是我们没做**，是 demo 原文件缺素材。
2. **垫板重编码是一处刻意的资产差异**：`static/kurisu/scene/subtitle_frame_big.webp` 我为了资产上限
   从 382,384 B 重编码到 86,918 B（2564×430 → 1024×172，显示尺寸约 400px 宽，肉眼几乎不可分）。
   demo 里是原图 → 这是 CRT 内部那 9.64% 的一部分。**要 100% 一致就说一句，我把它换回原图**
   （代价：资产 +295KB，仍在上限内）。
3. **`demo-flag` 橙色横幅没搬**：它写的是"主页 DEMO · 监测数字为演示数据"，是 demo 自己的标识，
   生产页搬它反而会挂着"演示数据"字样。**要搬我就搬（一行 markup + 一条 .demo-flag 规则已在 xk-app.css 里）。**
   它目前是差异热图左上/正中那块白的主要来源之一。
4. 角色轮廓的差异 = **帧序号不同**（demo 的循环停不下来，截图时在 idle 第 5 帧；我们冻在第 0 帧）
   + 上面第 2 点的垫板。这属于"她在动"，不是版式。
