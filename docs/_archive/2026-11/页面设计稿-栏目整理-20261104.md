# 页面上怎么改（详细设计稿）

> 配套文档：`栏目整理方案-20261104.md`（信息架构）。这一份只管**长什么样、量多少、怎么动**。
> 不变的前提：首页（CRT 舞台 + 角色 + 语音）一个字不动；所有页面内容不改写；不删页面。

---

## 1. 三条设计原则

1. **一个页面只回答一个问题。** 导航上每个词就是一个问题（现在被打成什么样 / 凭什么信 / 我练了什么 / 我学了什么）。
2. **信息靠"位置+字号+留白"分层，不靠颜色堆。** 全站只用两种强调色：青（信息）和珊瑚红（风险）。
3. **没有任何"悬空"的页面。** 任何二级页面顶部都有返回条，告诉你在哪一组、还有哪些同级。

## 2. 设计语言（沿用现有变量，不引入新色板）

### 2.1 颜色

| 用途 | 值 | 用在哪 |
|---|---|---|
| 底色 | `#070b0d` + 背景照 `bg-1920.webp`（叠 88% 暗层） | 全站 |
| 面板 | `rgba(12,18,22,.72)` + `backdrop-filter: blur(6px)` | 所有卡片 |
| 描边 | `rgba(127,211,227,.18)` | 卡片边框、分割线 |
| 主文字 | `#eef3f6` | 标题、数值 |
| 次文字 | `#9fb0ba` | 说明、单位、标注 |
| 弱文字 | `#6f828c` | 页脚、时间戳 |
| 强调（信息） | `#7fd3e3` | 链接、当前项、数字、图标 |
| 强调（风险） | `#ff7a6b` / `#ffc46b` | 严重 / 警告标签 |
| 健康 | `#8fe3a4` | 状态灯、"已拦" |

> 对比度：主文字对面板底 ≈ 13:1，次文字 ≈ 6.4:1，都过 AA。**新加的任何文字都不许低于 4.5:1**（85 项断言里有一条在查这个）。

### 2.2 字号与行高

| 层级 | 字号 / 行高 | 用途 |
|---|---|---|
| 页面大标题 | 30px / 1.25，字重 700 | 每页一个（如「更多」） |
| 分组标题 | 15px / 1.4，字重 600，青色 | 目录页的分组头 |
| 卡片标题 | 15px / 1.45，字重 600 | 目录卡、模块头 |
| 正文 | 14.5px / 1.7 | 段落、说明 |
| 表格正文 | 13px / 1.5 | 列表页 |
| 标注 | 12px / 1.5，`#9fb0ba` | 单位、时间、来源 |

中文统一 `Microsoft YaHei`；数字统一加 `font-variant-numeric: tabular-nums`（表格里数字要上下对齐）。

### 2.3 空间

- 栅格：内容最大宽 **1180px**，左右各 20px 内边距；桌面留出 96px 左侧 dock。
- 间距级差：`4 / 8 / 12 / 16 / 24 / 32`（不许用 5、7、13 这种）。
- 卡片：圆角 **14px**、内边距 **16~18px**、卡片间距 **14px**。
- 段落间距：12px；分组之间 32px。

### 2.4 组件清单（这次只用到 5 个，全部已有样式）

| 组件 | 规格 | 出现在 |
|---|---|---|
| 面板 `.mod` | 圆角 14 / 描边 / 模糊底 / 头部一条 `.mod-hd`（状态灯 + 标题 + 右侧小标签） | 全站 |
| 目录卡 | 面板 + 标题 + 一句话 + 右下角 2~3 个小标签 | `/more/` |
| 返回条 | 高 36px，左箭头 + 分组名 + 同级快捷入口 | 所有二级页 |
| 状态灯 | 8px 圆点 + 呼吸动画（2.4s）；不动效时静止 | 页面头、页脚 |
| 标签 `.tag` | 11.5px，圆角 999，描边 1px | 卡片、表格 |

## 3. 导航：10 → 6

### 3.1 桌面（≥ 981px）：左侧 96px 固定窄栏

```

│ 头像 │  42×42 圆角 10，右上角 ▾（30×30 热区）
│桐莉栖│  13px，左对齐
│待命 ●│  11px 青字 + 状态灯
│      │
│XK-LAB│  11px，字距 1px，#6f828c，分组小标题
│ 主页 │  ← 当前项：左侧 2px 青色竖条 + 底 rgba(127,211,227,.14)
│攻击实况│
│安全日报│
│攻防验证│
│ 笔记 │
│ 更多 │
└──────┘
```

- 每项：高 36px、内边距 `9px 14px`、字号 13px、左对齐。
- 当前项判定：`class="on"`（Hugo 里按 `$v` 匹配），样式复用现有 `.dock a.on`。
- 悬停：底色 `rgba(255,255,255,.04)`，**不加动效、不位移**（省得每次路过都抖一下）。
- 手机（≤ 980px）：dock 变顶部横向滚动条，只显示短标签，滚动吸附。

### 3.2 命名（只改字，不改路由）

| 现在 | 改成 | 理由 |
|---|---|---|
| 监测中心 | **攻击实况** | "监测中心"是内部视角，访客想知道"现在被打成什么样" |
| 靶场 | **攻防验证** | 一页里有靶场 + 红队 + 紫队，叫"靶场"漏了后两者 |
| （新增） | **更多** | 承接 11 个二级页 |

> 如果不想改标签，就保持原名——这两个词是"可选项"，方案不依赖它们。

### 4.2 目录卡规格

- 尺寸：桌面 3 列（`grid-template-columns: repeat(3, 1fr)`，gap 14px），平板 2 列，手机 1 列。
- 卡片内容自上而下：
  1. 标题（15px，600，主文字色）——就是页面原名；
  2. 一句话（13px，次文字色，**最多 2 行**，超出省略）——直接取各页 `_index.md` 的 `description` 前 40 字；
  3. 标签行（最多 3 个 11.5px 小标签，青色描边）——例如 `量化` `降噪`；
- 整卡可点（`<a>` 包住），悬停时**只提高描边透明度**（`.18 → .34`）并加 `translateY(-1px)`，150ms。
- 焦点态：`outline: 2px solid rgba(127,211,227,.55); outline-offset: 2px`（键盘可达）。

### 4.3 分组头

- 前置一个 3px 宽、18px 高的青色竖条（`▌`），文字 15px/600，右侧一条 `rgba(127,211,227,.12)` 的 1px 延长线到底（视觉上"这一段开始"）。
- 组间距 32px，组内卡片间距 14px。

### 4.4 空态与降级

- 不写交互、不 fetch：这是纯静态目录页，任何 JS 挂了它都能用（这是全站唯一"零 JS 依赖"的页面）。

## 5. 二级页面顶部返回条

所有 `/noise/ /ip/ /passwords/ /samples/ /redteam/ /purpleteam/ /status/ /api/ /what/ /projects/ /tools/ /ai/ /subscribe/` 的正文上方加一条 36px 高的横条：

```
┌──────────────────────────────────────────────────────────────┐
│ ← 更多 / 凭什么信这些数字      同级：噪音指数 · IP 档案 · 样本 │
└──────────────────────────────────────────────────────────────┘
```

- 左半：返回箭头 + `更多 / 分组名`，整块是一个 `<a href="/more/">`。
- 右半：同组其余页面的文字链（当前页不出现在里面），次文字色，悬停变青。
- 样式：无边框背景，只有底部一条 `rgba(127,211,227,.12)` 的 1px 线；字号 12.5px。
- 手机端：左侧保留，右侧同级链接隐藏（空间不够，横向滑动体验差）。

## 6. 页脚（全站统一）

一行，32px 高，弱文字色：

```
状态 ● 全部正常  ·  端点清单  ·  订阅  ·  关于  ·  © 2026 XK-LAB
```

- 状态灯：绿=正常，黄=有端点取不到，红=构建/发布异常；数据来自 `/status/` 已有的探测结果，不新增请求。
- 页脚在所有页面出现（包括首页），高度不占首屏（`position: static` 沉底）。

## 8. 可访问性与动效

- 所有可点元素：键盘 Tab 可达，焦点有 2px 青色 outline。
- 触控目标 ≥ 40×40（页面上的按钮类；纯文字链保持行高 1.6 即可）。
- 动效只有三处：状态灯呼吸（2.4s）、卡片悬停 1px 上移（150ms）、页面切换淡入（200ms）。**全部受 `prefers-reduced-motion` 约束**（已有实现，复用）。
- 不使用自动播放音频；音频仍需用户先点（现状已如此）。

## 10. 工时与验收

**工时**：目录页 40 min · 返回条 partial + 13 页插入 40 min · 导航与页脚 20 min · noindex 与样式 20 min · 构建 85 断言 + 发布 30 min = **约 2.5 小时**（比方案 A 的估算多 1 小时，因为加了返回条和页脚）。

**验收（逐条可测）**：

1. 桌面 1920 / 1280 / 1100 三档，导航一屏放得下、无横向滚动条。
2. `/more/` 上 12 张卡全部可点，卡片标题与目标页 `<title>` 一致，`description` 未截断到半个词。
3. 13 个二级页顶部都有返回条，点击回到 `/more/` 并定位到对应分组（锚点 `#g-evidence` 等）。
4. 键盘 Tab 走一遍：导航 → 6 张卡 → 页脚，焦点环全程可见。
5. 390px 宽下：目录卡单列、返回条只有左半边、无横向溢出（`scrollWidth === clientWidth`）。
6. 85 项构建断言全绿（含对比度、localhost、断链三项）；旧 URL 全部 200。
7. 3 Mbps 下 `/more/` 首屏 < 1.2 s（纯静态、零接口请求）。
