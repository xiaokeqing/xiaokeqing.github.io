## 一、本次落地的改动

### 1. 全局骨架屏与空态统一
- 新增 `.sk` 骨架呼吸条样式；取数成功后由 JS 自动摘除。
- 统一空态 `.na`：后端没数据时显示「读不到 /xxx」，不再用 `—` 或 `0` 混淆。
- 新增 `:focus-visible` 焦点描边，键盘 Tab 可见、鼠标点击不扰眼。

### 2. 监测中心（作战室）图形增强
- **实时攻击流**：每行左侧加级别色条；新增「暂停 / 继续」按钮，暂停时保留历史、继续时追加新事件。
- **24 小时攻击时序（spark24）**：补 X 轴刻度、峰值点、当前小时高亮；无数据时显示读不到。
- **告警来源甜甜圈**：把 `conic-gradient` 换成 SVG 分段弧，支持 hover 高亮、图例联动、`<title>` 读屏。
- **威胁矩阵**：hover 时显示摘要浮层，顶部加图例说明颜色含义。
- **空态**：所有子卡统一使用 `.na`，骨架屏在数据到达前展示。
- **Tab hash 直达**：`/alerts/#graph`、`/alerts/#matrix`、`/alerts/#stats`、`/alerts/#feed` 可直接打开对应 tab；切 tab 时写 hash，支持方向键切换。

### 3. AI 页对话组件升级
- **引用卡组**：答案底部「公开只读」引用区升级为「命中 N 条」可展开卡片，点击展开原文/标题/相关度/来源类型。
- **状态徽标分层**：按 state 分四档颜色渲染，为后端 A4 等新增状态预留分支。
- **示例问题 chips**：输入区上方展示 4 个示例问题，点击自动填入输入框，复用现有 `.anchor-row` 样式。

### 4. 主页 CRT 信息层增强
- **字幕下方真实事件行**：复用已取 `/api/public/audit` 的真实拦截事件，以滚播单行形式显示在 CRT 字幕下方，不新增请求。
- **状态行 count-up**：顶部 CRT 状态数字从 0 动画滚动到目标值。
- **宽屏值班便签**：≥1400px 宽屏右侧出现半透明「值班便签」卡，不遮挡人物主体，1280 及以下不出现。

### 5. 笔记页分类 chips
- `/posts/` 列表顶部新增分类 chips（全部 / AI 安全 / 安全运营 / 工程实践 / 随笔），Hugo 构建期按 categories 输出，前端过滤，零额外请求。
