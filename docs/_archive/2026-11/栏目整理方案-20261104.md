# 栏目整理方案（首页不动，2026-11-04）

> 前提：首页保持现在的 CRT 那套，一个字不改。这份方案只处理"首页之外的那些栏目怎么摆"。

---

## 一、先数清楚现在有多少东西

站里其实有 **17 个真页面**，导航里有 10 个，另外 7 个只能从别的页面点进去：

| 在导航里（10） | 不在导航里、被埋着的（7） |
|---|---|
| 主页 `/` | 告警噪音指数 `/noise/`（94.9% 是心跳噪音，量化过） |
| 监测中心 `/alerts/` | 这个 IP 干过什么 `/ip/`（个人版 AbuseIPDB） |
| 安全日报 `/daily/` | 高频弱口令 Top100 `/passwords/`（只给结构） |
| AI 问答 `/ai/` | 真实样本分析 `/samples/`（3 条攻击链） |
| 笔记 `/posts/` | 红队攻防榜 `/redteam/`（27 用例 / 4 条绕过） |
| 靶场 `/lab/`（7 台） | 紫队演练 `/purpleteam/`（自己打的能不能看见） |
| 状态 `/status/` | 项目 `/projects/`（5 个可核实记录） |
| 接口 `/api/`（20 端点） | |
| 工具 `/tools/`（CVE + 密码自查） | |
| 介绍 `/what/` | |

**这就是"杂乱"的真正原因**：不是栏目太多，而是**最有料的那几页被埋了**——噪音量化、IP 档案、弱口令结构、样本分析、红队 4 条绕过，这些是全场最硬的东西，访客根本找不到；而导航里排着"状态""接口"这种运维内部页。

还有两个开发页 `/demo/` `/test/` 和订阅页 `/subscribe/`，不该在客人动线上。

---

## 二、目标（三条，满足就算整理好了）

1. **一屏能看完**：导航不超过 6 项，不用滚动。
2. **分组有语义**：每一组回答一个问题——"现在发生什么 / 凭什么信 / 我练了什么 / 我学了什么"。
3. **好东西不许埋**：噪音/IP/弱口令/样本/红队/紫队 必须在两次点击内到达。

---

## 三、方案 A（推荐，1.5 小时，今天能上）

### 3.1 导航 10 → 6

```
主页            /                    ← 不动
攻击实况        /alerts/             ← 改标签：监测中心 → 攻击实况
安全日报        /daily/              ← 不动
攻防验证        /lab/                ← 改标签：靶场 → 攻防验证
笔记            /posts/              ← 不动
更多            /more/               ← 新建（唯一新页面）
```

### 3.2 新建一个 `/more/` 目录页（这页是整理的核心）

不写新内容，只把被埋的 11 个页面**按组列出来，每页一句话**（直接复用各页已有的 description）。分四组：

| 组 | 页面 | 一句话 |
|---|---|---|
| **凭什么信这些数字** | `/noise/` | 29 万条告警里 94.9% 是心跳噪音——把降噪量化出来 |
| | `/ip/` | 输入一个 IP，看它在本站干过什么（个人版 AbuseIPDB） |
| | `/passwords/` | 蜜罐收到的口令：只给结构，不给明文 |
| | `/samples/` | 3 条真实攻击链，0 个文件留存（如实说抓不到） |
| | `/api/` | 20 个公开端点，每个都能 curl 复核 |
| **我练了什么** | `/redteam/` | 27 条用例实跑，4 条还没挡住 |
| | `/purpleteam/` | 我打的攻击，我的平台能不能看见 |
| **这台机器本身** | `/status/` | 现在能不能用、数据新不新 |
| | `/what/` | 这是什么、能干什么（一段话） |
| | `/projects/` | 5 个可核实的项目记录 |
| **顺手的小工具** | `/tools/` | CVE 每日速递 + 你的密码在不在字典里 |
| | `/ai/` | 问安全概念，答不出来就说不知道 |
| （页脚） | `/subscribe/` | 订阅 |

### 3.3 顺带三件小事（同一次做完）

- `/demo/` `/test/` 加 `noindex` 并断开任何链入，不当成客人动线。
- 每个二级页面顶部加一条**同组返回条**（"← 更多 / 凭什么信这些数字"），让人随时知道自己在哪。
- 页脚统一放：状态灯 · 端点清单 · 订阅 · 关于。

### 3.4 旧地址

全部 200 不变（只是不在导航里了），外链不断。

### 3.5 工时

`/more/` 目录页 40 分钟 · 导航与标签 20 分钟 · 返回条 20 分钟 · 构建断言发布 30 分钟 = **1.5 小时，当天上线**。

## 四、方案 B（进阶，4 小时，等 A 跑一阵再说）

把"更多"升级成 4 个真栏目首页（各带页签），导航只留 5 项：

```
主页 · 攻击实况(+日报+状态) · 证据(+噪音+IP+弱口令+样本+接口) · 攻防验证(+靶场+红队+紫队) · 笔记 · 关于(+这是什么+项目+工具)
```

好处：每一组有自己的封面和导语，像一本书的章。代价：要新建 4 个 hub 页、改 12 个页面的导航高亮逻辑，风险比 A 大，收益主要在观感。

---

## 五、不做的事

- **不动首页**（站主要求）。
- **不删任何页面**（17 个全留，只是有的不在导航里）。
- **不改页面内容**（除了加返回条和 `noindex`）。
- **不动后端**。
