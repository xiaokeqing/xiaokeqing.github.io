### A 安全数据面

#### ① 蜜罐与检测栈部署运营 · **在跑**

- **目标**：两台云服务器上**真实**跑一套蜜罐与检测栈，为整站提供"不是截图"的真实攻击数据源。
- **现状**：srv2 = 腾讯云 4 vCPU / 3719 MB，**7 个容器**（cowrie / dionaea / secagent-decoy / suricata / wazuh.dashboard / indexer / manager）+ 蜜罐网段 `172.19.0.0/16`；
  srv1 = 阿里云 2 vCPU / 1870 MB，跑自研 SecAgent 检测与处置链 + 公开只读 API。隔离回归：蜜罐网段对外 9 端口 SYN=0（对照 SYN=3）、7 容器全 Up ✓；运维自动化 = 备份 / 证书告警 / 5 分钟可用性探测。
- **实现要点**：Wazuh·Suricata·Cowrie·Dionaea = **集成开源**（检测数据的那一头）；SecAgent = **自研**（源码在单独后端仓库）；站点托管与蜜罐**同机**（srv2）—— 已知的单点耦合。
- **验收标准**：① 7 容器全 Up 且蜜罐网段对外 SYN=0；② 站点被刷时蜜罐与检测栈不受影响（**未压测** ✗）；③ 公开只读端点全部来自真实日志的聚合脱敏结果（可抽查一条告警回源）。
- **依赖**：srv1 / srv2 实例与安全组；证书 LE 4-SAN 到期 2027-01-12。
- **工作量**：运营无新增；**服务端历史待办 7 项**（案例管理/playbooks · MTTD/MTTC · Trivy 分级 · ACR 陈旧镜像告警 · 管理员密码轮换 · 日志脱敏 · Wazuh 盯 web 进程）**未查到任何后续文档确认已做** ⇒ `[待核对]`，工时未给。

#### ② 实时监测中心（告警流 / 威胁等级 / TOP 来源 / 类型矩阵 / 国别 ASN / 时序） · **已上线**

- **目标**：把真实攻击流做成人能看懂的一页"作战室"。
- **现状**：`/alerts/` 展示告警流（终端 tail 样式）、威胁等级、TOP 来源、攻击类型矩阵、来源国 / ASN，以及 24h 按小时分桶时序（端点支持 `1h/6h/24h/72h`，默认 24h）；页面**已上屏**（线上 200）。
  端点规模口径：**9 个 GET 固定路径**，加路径参数 10、查询参数 11、加 `POST ask` 12 —— 但另两份文档记 **12** 与 **8（漏 3 个）**、双智能体规格记**11**，**三说不一致** ✗。实测 `alerts 2.201s`（单次样本，含冷快照因素，**根因未定论**）。
- **实现要点**：数据全部来自公开只读端点的聚合结果，**前端不轮询**；慢端点统一 **22s 超时 + 失败重试 2 次（退避 1s/3s）**，失败保留上次成功数据并写"接口慢 / 正在重试"；空态纪律取不到写"读不到"。门禁页数 4 → **5**。
- **验收标准**：① 六块各有真实响应体可回源；② 断开后端时显示"读不到"而不是数字（空态截图）；③ 页面上**不出现**访客 IP 与内网 IP；④ 端点条数**以实测枚举收口**后再写进文档。
- **依赖**：①（数据源）、公开只读 GET 白名单（`scripts/assert-build.sh` 第⑥条）。
- **工作量**：已交付；端点条数收口 `[本文件规划值]` **2~4h**（只读枚举 + 文档订正，不动代码）。

#### ③ 攻击溯源故事线（四类事件聚合 + 单源下钻） · **已上线**

- **目标**：把"谁在打、打了多久、打到哪几段"讲成一条时间线。
- **现状**：候选池 `GET /api/public/stories` 给每个来源四段计数（`alerts / decoyPorts / honeypotLogins /auditActions`）、首末时间、最高严重度、缺口与覆盖度；
  实测 24h `candidates=137`（另一轮 135）、`sourceCount=10`。下钻 `GET /api/public/story?src=` **点击才懒加载**（唯一新请求，15s 缓存），`events[]` 升序、每段 ≤40 条、`truncated` 如实标注；
  点击前 `/story` 请求数 **0**。⚠️ **缺口**：`auditActions` **10/10 来源全为 0**（两轮复测一致）。
- **实现要点**：后端区分"没接入"与"没发生"—— `coverage.status=NOT_WIRED` 与 `gaps` 两条语义，前端据此写"这一段尚未接入"或"该来源这一段确实没有数据"，**两者绝不混写**（`api-bind.html` L497 已实现）。
- **验收标准**：① 点击前 `/story` 请求数 = 0（CDP 取证）；② 四段计数与响应体逐字段一致；③ `truncated=true` 时必须显示"已截断"；④ 两种措辞各自截图、**互不串用**；⑤ `auditActions` 恒 0 的根因有结论。
- **依赖 + 工作量**：①、公开只读端点、空闲预取（`manifest.json` / `video-manifest.json` / `bank.json` 在 2000ms 后取）；已交付，`auditActions` 段根因复核 `[本文件规划值]` **1~2h**（只读 curl + 口径核对，不含改后端）。

#### ④ 自动化处置与封禁（规则判定 + 高危人工审批 + 护栏 + 留痕） · **在跑**

- **目标**：讲清"不只看，还会动手处置"，且处置**有护栏、有留痕、可追责**。
- **现状**：数据源 `GET /api/public/audit` = 汇总四数 + 榜单行（脱敏 IP · `durationMinutes` · `source`（智能体/手动）·`actor` · 创建时间 · 是否已解封 · 解封方式 · 留痕号 `auditId`）。
  实测 `blockTotal=10`、`blockActive=0`、`blockedByGuard=26`、`executedActions=20`；审计台账 `response-audit` **46 条**、`blocked-ips` **10 条**，与 `/audit` 实测一致 ✓（两处文档 + 实测三方对齐）。
- **实现要点**：执行入口**只有技能层能调**且**必须带审批凭证**；人格层只读 + 只提议（见 §③ 规则 3）；写库 / 封禁 /动容器仅技能层；公开面 `toolExecutionAllowed=false` 恒真。
- **验收标准**：① 榜单每行字段可回源到 `/audit`；② DOM 里**不出现完整四段 IP**（自动化断言）；③ `reason` 过自由文本脱敏；④ `blockedByGuard=26` 能解释是哪类动作被拦；⑤ 高危动作确有人工审批痕迹（`actor` 可辩识）。
- **依赖**：①、SecAgent 技能层与审批凭证机制、前端空态纪律。
- **工作量**：上屏已交付；后续加固（跨机 IMDS 访问、容器逃逸）来源为"站主发的安全提示文档"，该文件不在本仓库、**本次未读到** ⇒ `[待核对]`。

#### ⑤ 数据出口闸门与隐私（IP 分段掩码 / 凭据结构 / 自由文本过滤 + 回归测试 / 零泄漏） · **部分**

- **目标**：任何出海到页面的字节里，**不含访客 IP、不含内网地址、不含凭据原文**。
- **现状**：攻击者 IP **保留前三段、末段换 `x`**；**掩码只作用于显示**，用于分组的原始值不许改（否则同 /24 被合并）。调用者地址只出掩码（`clientIpMasked = 47.96.***.***`）、`ipDisclosure.masked` **恒true**（与全局开关无关）。
  结构化 IP 走 `policy().display(...)`；**自由文本**（`title` / `ruleName` / `events[].summary`）走**唯一出海闸门**`scrubText() →policy().displayText(...)`。
  线上实测 `embeddedGitCommit=2bb2b2d`、`fingerprintMismatch=false`、`documentVectors=318`；整份 `/ask` 响应体 dotted-quad 正则 **0 命中**，`/geo` 与 `/webstats` 响应**零 IP** ✓。
  蜜罐凭据以"结构 + 频次"上屏（用户名首字母 + 长度、口令只给统计口径、自由文本 IPv4/IPv6 **全替换**）。⚠️ **两处不一致**：① `api-bind.html` L167/L223/L276/L335 仍打**完整 IP**（站主已裁定"不算违规、非必须改"）；
  ② 蜜罐 `total=10000` 仍按真实总数展示 —— 它是**统计上限**（同响应 `connections=267`、`logins=267`、`sampled=800`三者互斥），HANDOFF §3① 的修法是 `≥10000（统计上限）`，落点 L167/L209 两行，**本次实测仍是
  `fmt(hp.total)`** ✗。
- **实现要点**：修在**闸门**而不是逐个构造函数里补 —— 同一类失败模式出现过两次（口令一次、内网地址一次），根因都是"闸门没覆盖到某个自由文本字段" ⇒ 验收要压的是**闸门覆盖率**，不是单点 case。
- **验收标准**：① 自由文本闸门有**回归测试**（后端单测含该闸门 4 条；总数 **610 run / 0 fail / 4 skip**）；② 对`/ask`、`/audit`、`/alerts`、`/honeypot`、`/stories`、`/story`、`/kb`、`/geo`、`/webstats` 逐个跑
  dotted-quad 正则，命中 **0**；③ 页面上不出现访客 / 内网 IP（DOM 断言）；④ **上限值 / 截断值必须显式标注**（`total` 是当前唯一未达标项 ✗）；⑤ 掩码函数对已掩码值**幂等**。
- **依赖**：后端 `policy()` / `scrubText()`、前端 `maskIp()`、后端重建（如需扩字段）。
- **工作量**：存量 B7（三处完整 IP）**条目自带"非必须"、未给工时**；蜜罐 `total` 两行 `[本文件规划值]` **≤0.5h**。

### B 问答与 AI

#### ⑥ RAG 安全问答（双路召回 + RRF + 重排 + 引用溯源 + 拒答） · **已上线**

## ③ 跨模块的横切规则（**评审最该看这一节**）

1. **零造假红线**：数字只来自真实只读接口；**取不到就写"读不到"**，不补样例；"这一段确实没有数据"与"这一段尚未
   接入"**必须分开措辞**（`coverage.status=NOT_WIRED` vs `gaps`）；**上限值 / 截断值必须显式标注**（蜜罐
   `total=10000` 是当前唯一已识别的未达标项 ✗）；未接线的能力标 `NOT_WIRED` 并写清"接上时的落点"。
   → 落地检查点：⑤（闸门）、⑮（失败只出字幕）、③（两段语义）、⑱（徽章）。
2. **IP 显示口径**：攻击者 IP **保留前三段、末段换 `x`**；**掩码只作用于显示**，用于**分组的原始值不许改**（否则同
   /24 攻击者被合并，统计口径被污染）；掩码函数对已掩码值**幂等**；**唯一真红线 = 访客自己的 IP 与内网地址一律
   不上页面**。该口径在后端（`policy().display` / `displayText`）与前端（`maskIp`）两处实现，必须同口径。
3. **人格层不进执行链**：人格层**只读 + 只提议**；执行入口只有**技能层**能调且**必须带审批凭证**；`publicDemo=true`
   + **`toolExecutionAllowed=false` 恒真**；写库 / 封禁 / 动容器**仅技能层**。穷举权限矩阵 + 枚举白名单 + 输出
   净化器 ⇒ **提示词注入只能改变语气、改不了权限**；边界由**构建期测试**钉住，不由提示词保证。
4. **一次一批 + 三绿门禁 + 精确 ref + 可回滚**：一次一批、一个归属人（两条线同时改 `nginx.conf` 曾致 ~30s 502）；
   发布前必须三绿 + console 0；按**精确 ref** 发布（不是浮动 latest）；`KEEP=4`；每批留**改前 / 改后截图**与机器
   可读取证；失败立刻回滚并**定位根因**后重发；只 `git add` 自己的路径（禁 `git add -A`、禁带 `public/`、`_shots/`）。
5. **生成物 vs 手写件**：`layouts/partials/xk-demo/**`（除 `test-lab.html`）= **生成物**，源在 `_dev/gen-demo-pages.py`
   （`IDCARD_PARTIAL` / `LAZY_PATCHES` 等）⇒ **改生成物必须先改生成器再重跑**；`test-lab.html` = **手写件**可直接改；
   `statemachine.json` 与 `manifest.json` 会被生成器**重写**；跑生成器还会动 `static/**` ⇒ 素材批次必须先确认闭环。
6. **口径半衰期**：线上"当前 release / 页面字节 / 端点数"**落笔即过期**（实测过 25 分钟内发布 3 次）⇒ 评审时**以实测
   为准**；判据用 `readlink -f`（不是 `ls -l` 的 mtime）；轻量测量必须配**正确口径**（`visualViewport.width` 而不是
   `innerWidth`），否则会得出反向结论。
