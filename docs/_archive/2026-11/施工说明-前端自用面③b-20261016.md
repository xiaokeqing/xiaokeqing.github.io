## 2. 后端现测事实（可直接当基准）

**令牌面（`/api/user/**`）**
- 端点基址：**`https://demo.xiaokeqing.cn`**（页面 `<meta name="wb-api">`，`gen-demo-pages.py:152`；**不要在 JS 里写死域名**）
- 必须带请求头 **`X-User-Token`**（值 = 站主粘贴的令牌原文）
- 跨域预检已放行：`access-control-allow-headers: x-user-token`、`access-control-allow-origin: https://xiaokeqing.cn`
- **限流桶：每 IP 10 次/分钟，且 `GET /api/user/status` 与 `POST /api/user/ask` 共用同一个桶**（`app.ratelimit.login-per-minute:10`，独立于公开面 20/分与全局 30/分）⇒ **别在探针里循环打 status 探测**（会把提问额度挤掉，被挤到就是白等）
- srv2 上**不需要**为 `/api/user/` 加反代（`xiaokeqing.cn` 是静态站，`/api/*` 落到 SPA 兜底返回 `index.html` 是预期）

**`GET /api/user/status`（成功 200）** — 现测字段
```json
{"code":200,"message":"success","data":{
  "loggedIn": true, "authenticated": true, "pool": "self", "generatedAt": "…",
  "quota": {"pool":"self","softLimit":true,"available":true,"limit":500,"used":2,
            "remaining":498,"softLimitReached":false,"storeFile":"…","note":"…"},
  "conversation": {"maxRounds":5,"ttlMinutes":30},
  "limits": {"maxBodyChars":4000,"deadlineMs":60000,"maxTokens":4000},
  "note": "…"
}}
```
> 契约 §10.3 的 `storeFile` 等字段属内部路径，**前端不要渲染**（与"不露内部信息"同口径）。

**`POST /api/user/ask`** — 契约 §10.4（逐字）
```jsonc
// 请求：{"question":"…","conversationId":"xk-<随机>"}   // conversationId 可省；省了后端生成并在响应里回
// 成功 data：{"answer":"…","state":"model","generated":true,"round":2,
//            "conversationId":"xk-…","maxRounds":5,"historyRounds":1,
//            "citations":[…],"citationsInAnswer":true,"pool":"self",
//            "clientIpMasked":"…","quota":{…},"toolExecutionAllowed":true}
// 未生成：HTTP 仍 200，但 state=model-failed / generated=false ⇒ 必须按"未生成"显示，
//         不许把 answer 当结论渲染
```

> ⚠️ **一条安全提醒（后端线 2026-10-16 实测）**：`prometheus.mock-enabled` / `cls.mock-enabled` 默认 `true`，而**自用面 `toolExecutionAllowed=true`**（公开面是 `false`）⇒ 登录后问"最近有什么告警"时，**回答可能引用模拟指标**。③b 落地时若展示"用了哪些工具/数据来源"，**必须如实标注来源**，不许把模拟值当真值呈现（这条同时是给站主的知情项）。

## 3. 请求头与令牌纪律（红线，逐条照做）

| 项 | 约定 |
|---|---|
| 头名 | `X-User-Token` |
| 头值来源 | **只**从 `localStorage['xk-user-token']` 读（③a 已实现 `userToken()`） |
| 出现范围 | **只**发给与 `meta[name=wb-api]` **同源**的 URL（③a 的 `sameAsApi(u)` 已在 `api-bind`/`idcard` 两处把关） |
| ✗ 禁止 | 令牌写进任何 `.js`/`.html`/模板/构建产物/仓库文件；写进 `document.cookie`；放进 URL 查询串（会进历史/Referer/日志） |
| 退出 | `localStorage.removeItem('xk-user-token')`（本地即可，后端无会话可销） |
| 坏令牌 | 401 时**不要**立刻删本地值（可能只是粘贴出错）——③a 已按此实现 |

## 5. 错误分支与文案（逐字，可直接用）

**五条契约文案（§10.5）**

| # | 触发 | 文案 |
|---|---|---|
| 1 | 未登录时点 👤 | 「自用入口：请粘贴自用令牌（令牌只保存在本机浏览器，不会上传到别处）」 |
| 2 | 401 `TOKEN_INVALID` / `TOKEN_MISSING` | 「令牌无效或已轮换 —— 请向站主要一份新的自用令牌」 |
| 3 | 401 `USER_LOGIN_DISABLED` | 「自用入口当前未启用（服务端未配置令牌）」 |
| 4 | 429 `LOGIN_RATE_LIMITED` / `IP_TEMPORARILY_BANNED` | 「尝试过于频繁，请 N 秒后再试」 |
| 5 | 200 且 `quota.softLimitReached=true` | 「今日自用调用已达软上限 500 次，**仍可继续使用**（仅提醒，不限额）」 |

**两条补充**
- `state=model-failed` / `generated=false` ⇒ 「本次没有生成结论（模型或链路不可用）」——**不要**把正文当答案（`answer` 里写明了没有结论）。
- 网络失败或 5xx ⇒ 「连不上服务，请稍后重试」；**不要**因此清掉 `localStorage`。

**N（限流秒数）取法：三层兜底**（与 `docs/批次3a…` §四 同口径）
1. 响应头 `Retry-After` —— **跨域下浏览器默认读不到**（`Retry-After` 不在 CORS 安全列表响应头里）
2. 响应体 `retryAfter`（`body.retryAfter` / `body.data.retryAfter`）
3. 默认 **60**

> ✅ **这一层已修好**：后端批 `579cfe1`（接手窗口提交、**待发布**）给业务面加了 `Access-Control-Expose-Headers: Retry-After`，并在 429 的**头与体**两处都给秒数。⇒ 部署后第 1 层可用；**在第 2/3 层同时保留**（幂等，不会退化成"永远 60"）。

## 7. 验收清单（建议直接写成探针断言）

参考现成套路：`_dev/probe-3a-login.mjs`（用 CDP 的 `Fetch` 域**拦截** `demo.xiaokeqing.cn` 自己造响应 ⇒ 离线、确定性、可重复）。③b 建议断言：

1. 未登录（无令牌）：点 👤 后**不发任何** `/api/user/*` 请求（计数 0）
2. 真令牌：`GET /api/user/status` 200 且 `loggedIn===true` ⇒ `state='logged-in'`、按钮显示 🔓
3. 提问：`POST /api/user/ask` 的请求头含 `X-User-Token`、body **只有** `{question, conversationId?}`
4. **令牌只发 `wb-api` 同源**：断言所有带 `X-User-Token` 的请求 URL 均以 `https://demo.xiaokeqing.cn` 开头
5. 多轮：第二次提问带上第一次响应回的 `conversationId`；窗口满 5 轮时后端 `round`/`historyRounds` 行为与文案一致
6. `state=model-failed` / `generated=false` ⇒ 显示"本次没有生成结论"，**不**渲染为答案
7. 429（造头内 `Retry-After: 7` / 造体 `retryAfter: 9` / 都不给）：三种都要拿到正确 N（7 / 9 / 60）
8. `quota.softLimitReached=true` ⇒ 显示第 5 条文案且**输入框仍可用**
9. 退出：出 `confirm` → 键被删 → `state='anon'` → 会话 id 一并清掉
10. 页面里**搜不到任何令牌字面量**；`console` 全程 **0**
11. 未登录访客：`/api/user/*` 与 `/api/public/ask` 请求数**都为 0**

**门禁（沿用项目仪式）**：`hugo --gc --minify -d <独立目录>` → `python -X utf8 _dev/check-ssr-contract.py <独立目录>`（5/5）→ 首屏门禁 warm/cold → 改前/改后截图。**别碰共享的 `public/`**（并发线会互相覆盖；本窗口已确立"每条线用独立 `-d` 目录"的做法）。
