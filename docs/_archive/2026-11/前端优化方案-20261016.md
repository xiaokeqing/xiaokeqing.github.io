## 1. 分页面优化方案（视觉/布局/交互，全在现有令牌体系内）

### 1.1 主页：让 CRT 这块屏幕"真的在干活"

问题：CRT 状态行三个数字在取数回来前全是「—」，失败时含义不清；字幕条只轮一句台词；桌面宽屏下 desk 两侧大面积暗区闲置。

1. **CRT 状态行升级为迷你仪表条**（改生成器里主页状态行那段 + `api-bind.html` 已有的主页三端点绑定）
   - 数字 count-up 入场（rAF 改 textContent，合规）；失败时按既有纪律显示「上次同步 X 分钟前」快照态，不留「—」。
2. **字幕条双行化**：上行角色台词（现状），下行滚动一条真实事件摘要（复用主页已取的 `/audit` 数据，**不新增请求**）——例：「刚刚拦下 45.83.\*\*\*.\*\*\* 的 SSH 暴力破解 · 已封禁 30 分钟」。访客第一眼就看到"真在跑"。
3. **宽屏（≥1400px）右侧加一张「值班便签」**：半透明 panel 小卡（复用 `--panel/--line2` 令牌），放今日拦截 TOP1 类型 + 「进作战室 →」链接。只在宽屏渲染（媒体查询），≤1399px 不出现，不盖人物、不动底图。
4. **移动端**：CRT 状态行在 375/390/414 下字号太小，改为屏外一行小字带（仍用 panel 变量），字幕保持屏内。

### 1.2 监测中心：图形件从"能用"到"可信"

1. **实时攻击 tab**
   - term 流：每行左侧加 2px 级别色条（复用 `.tl .ssh/.scan/.web` 现有色，不新增色值）；加「暂停滚动」按钮（自动流可控性，a11y 要求）。
   - spark24（canvas）：补横轴刻度（0/6/12/18/24h）+ 峰值点标记 + 当前小时高亮柱。现在是一条"裸线"，读不出量级。
2. **攻击图谱 tab**
   - 节点 hover 出 tooltip（掩码后网段 + 命中次数 + 最近类型）；命中边加"时间衰减"（老边淡出、新命中脉冲一次）。
   - 底部加 24h 回放滑块：拖动重绘（纯前端重放已取数据，**不轮询、不新增请求**）。
3. **威胁矩阵 tab**
   - 格子 hover 展开「该类型最近一条事件摘要」（从已取 alerts 前端聚合，不新请求）；补热度图例（冷→热三档色块说明，用现有 hot/fire 档）。
4. **数据统计 tab**
   - donut 升级：CSS conic-gradient 换成 **SVG 分段弧**（stroke-dasharray），hover 分段高亮 + 中心显示该段数值（见 §3 选型理由）。
   - geo TOP5 数值 count-up；所有 `.stat` 大数字统一 count-up。
   - 故事线/封禁榜（已接线）补「上次同步」时间戳，与全站口径一致。
5. **通用**：tab 切换加键盘左右键支持；空态统一成一个 `.na` 样式（现在各处「读不到」样式不齐）。

### 1.3 AI 问答：把"可信"做成看得见的组件

1. **引用卡升级**（`.cite` → 引用卡组）：标题行「引用命中 N 条」（B5 那行真值），每条可展开显示来源白名单目录 + 片段；命中 0 条时明确显示「无引用 · 已拒答」状态徽标。
2. **状态徽标分层**（为后端 A4 预留位）：`ok / no-kb-basis / no-live-data / model-failed` 四档 chip，前端先把渲染分支写好，后端状态一到即上屏。
3. **输入区加示例问题 chips**（复用 KB 卡已有的 `anchor-row` 胶囊样式，视觉零新增）。
4. **手机框角色状态联动收口**：lab ⑧⑨ 的实验成果正式落到这页——`IDLE/LISTENING/THINKING/SPEAKING` 四态映射到底部 bars2 与 `phoneLine`，提问→等待→回答全程有反馈（现在回答等待期手机框是死的）。

### 1.4 笔记：最低成本提密度

1. **列表页顶部加分类 chips 行**（渗透文档/课堂笔记/个人总结/CVE/速查），Hugo 构建期按 front-matter `categories` 输出，**纯模板零 JS 零请求**；点 chip 前端过滤已渲染列表。
2. 每条笔记补 tags 小字（现有 `.ds` 行内追加，样式不动）。
3. **阅读页**：确认三栏现状后补 TOC（构建期 `.TableOfContents` + 滚动高亮）与右侧上下篇/字数栏；这是规格书 §4-② 里写了但还没落地的部分。

### 1.5 全局

1. **骨架屏**：各处「—」占位换成 CSS 骨架条（`opacity` 呼吸动画，transform/opacity 规矩内），取数回来再填值——首屏观感提升最大的一项。
2. **焦点态**：dock/按钮/输入框补 `:focus-visible` 描边（用现有 `--acc`，不动配色）。
3. holo 面板与手机框的状态词表统一（现在 SPEAKING/IDLE 两处口径不一致）。

## 3. 图形化实现选型（零第三方约束下）

决策规则：**能 CSS 不 SVG，能 SVG 不 Canvas；只有"实时/动画/大量节点"才上 Canvas**。

| 图表类型 | 技术 | 理由 | 现状 |
|---|---|---|---|
| 柱状图（webstats） | 纯 CSS flex bars | 现做法 ✓ 零成本、自适应 | 保持 |
| 比例环（bySource donut） | **改 SVG 分段弧** | conic-gradient 没法做分段 hover/高亮；SVG 可挂 `<title>` 做 a11y、可加事件 | 建议升级 |
| 时序 sparkline（24h） | Canvas（现状）| 逐帧动画需要；补刻度/峰值即可 | 保持+增强 |
| 攻击图谱 | Canvas（现状）| 节点脉冲/衰减动画必须 Canvas | 保持+增强 |
| 威胁矩阵热力 | CSS 格子 | 现做法 ✓ | 保持+hover |
| 折线/面积图（未来趋势类新图） | SVG path | 静态统计图 SSR 可出、可打印、自带 a11y | 选型备用 |
| 雷达图（如 AI 评测维度，未来） | SVG polygon | 同上 | 选型备用 |
