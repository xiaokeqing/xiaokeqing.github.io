> 这份文件回答四个问题：**这是什么、能看什么、怎么跑、怎么验**。
> 其它文档都是过程记录（§21–§34 在 `Amadeus-项目总文档-20261017.md`），这份是"从零接手"的唯一入口。

## 1. 这是什么

一套**放在公网上的个人安全观测站**：两台云主机 + 一套只读数据接口 + 一个 Hugo 静态站。

```
采集（srv2）                    处理（srv1）                展示（srv2）
Wazuh / Suricata / 蜜罐  ──►  Spring Boot 20 个公开端点  ──►  xiaokeqing.cn（静态站）
13 个容器                      快照缓存 45 s / SWR 300 s      每 60 s 自己刷新
```

- 站点：`https://xiaokeqing.cn/`
- 接口：`https://demo.xiaokeqing.cn/`（全部只读，`/api/public/*`）
- 私有接口：`/api/user/*`（未登录一律 401，fail-closed）

## 3. 怎么跑

**站点（本机）**

```powershell
cd F:\7AAA\AI\blog
hugo --gc --minify --cleanDestinationDir          # 产物在 public/
python -m http.server 1313 -d public              # 本地看：http://127.0.0.1:1313/
```

> 本地起服务请用 **1313** 端口：接口的 CORS 白名单只认 `https://xiaokeqing.cn` / `https://www.xiaokeqing.cn` / `http://localhost:1313` / `http://127.0.0.1:1313`。

**站点（线上）**

```powershell
# 构建 + 90 项断言 + 打包 → scp → srv2 原子切换 → 整树哈希核对 → release-info → CF 缓存清理
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish-site-to-srv2.ps1 -FromRef HEAD
```

> 发布前必须把 `WindowsApps` 从 PATH 里剔掉（否则 `python3` 会命中应用商店占位程序、⑯⑰ 两项假失败）。
> 不要加 `-CheckUrl`：本机到 Cloudflare 会偶发 `HTTP 000`，卡在 6.5 之前。

**后端（srv1）**

```powershell
& 'F:\Maven\apache-maven-3.9.12-bin\apache-maven-3.9.12\bin\mvn.cmd' -q -o -DskipTests package   # 出 jar
# 推镜像到 ACR stable（必须带 OCI label）→ systemctl start secagent-redeploy.service
```

> 镜像必须带 `org.opencontainers.image.revision` 与 `artifact-md5`，否则 `srv1-redeploy.sh` 会 fail-closed 拒绝；
> `deploy-remote-build.ps1 -SkipBuild` 只是本机快速验证，5 分钟内会被 `secagent-redeploy.timer` 按 ACR 指针回滚。

## 4. 怎么验（两条命令）

```bash
# ① 线上自检：15 个页面 + 6 条内容特征 + 4 个接口 + 登录必须 401
python3 scripts/site-check.py --base https://xiaokeqing.cn --api https://demo.xiaokeqing.cn

# ② 数字复算：把文档里写过的数字重新算一遍，对不上就报错
python3 scripts/audit-numbers.py --group api      # 在 srv1 上跑（接口在 srv1）
python3 scripts/audit-numbers.py --group site     # 在 srv2 上跑（站点在 srv2）
```

两个脚本都只读、不改数据。`site-check` 退出码：0 全过 / 1 有失败 / 2 有提醒。

**构建期防手滑**：`bash scripts/assert-build.sh public` = 90 项断言（页面存在性、资产字节上限、表头、懒加载、
慢网判定、门页只有开屏画布、locahost 只允许出现在提示符里……）。断言不过就不准发布。

## 6. 明确不做（及原因）

| 不做 | 原因 |
|---|---|
| 评论 / 注册 / 多租户 | 单人站，注册会引入滥用面；登录只给站主（邮箱验证码，白名单仅一人） |
| 对外靶场 | 靶场只开在自己机器里，绝不对公网开放 |
| App / 小程序 | 静态站 + 响应式已够 |
| 短信告警 | 邮件已够，短信有成本且扰民 |
| `/ai/` E-mote 11.6 MB 瘦身 | 纹理尺寸烘进了模型切片坐标，不重导模型压不下去（实验见 §24.7） |
| 视频档人物再提分辨率 | 268×360 已是"清晰度 vs 3 Mbps"的平衡点，再提会顶爆首屏预算 |
