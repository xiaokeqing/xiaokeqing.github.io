## 6. 人名读音处理（★ 引用窗口 J 的结论）

**J 的结论（我独立复现了它的核心一步）** `[已实测]`：根因不是"合成念歪"的随机问题，而是 **日文文本前端（pyopenjtalk / Open JTalk）把「牧瀬紅莉栖」读错**：

```
pyopenjtalk.g2p('牧瀬紅莉栖よ') → m a k I s e k u r e n a i r i i s u m i k a y o
                                   （=「マキセクレナイリースミカ」：紅→クレナイ、栖→リースミカ）✗
pyopenjtalk.g2p('牧瀬クリスよ') → m a k I s e k u r i s u y o     （=「マキセクリス」）✓
run_frontend('…牧瀬クリスよ…') 的 CAT 词条：`牧瀬 / read マキセ / acc 1` + `クリス / read クリス / acc 1`（两个独立词，可正常连读）✓
```
这与 J 的判定一致：换参考音频、换模型（v1/v2/v2Pro/v2ProPlus/v3 同一个日文前端）、拆句都**不解决** ✗。

**我做的处理（①假名兜底，机制落地）** `[已实测]`：

1. 双语库加**朗读文本覆盖字段** `ttsJa`（`scripts/voice/lines60-bilingual.json`，并在顶层写明 `ttsFieldOverride` 语义）：
   ```
   greet_first_ever   ja    = はじめまして。牧瀬紅莉栖よ——名前、間違えないで。      ← 显示原文，**未改** ✓
                      ttsJa = はじめまして。牧瀬クリスよ——名前、間違えないで。      ← 送 TTS 的朗读文本 ✓
                      zh    = 初次见面。我是牧濑红莉栖——名字别念错。                ← 字幕，**未改** ✓
   ```
   全库含「牧瀬紅莉栖」的台词共 **1 条**（就是这个 id）；脚本 `ab3\add_ttsja.py` 可重跑。
2. `scripts/voice/synth.py` 改为 `ttsJa` 优先：`text = line.get("ttsJa") or line.get("ja") or line.get("text")`
   —— **只影响送进 TTS 的文本**，`bank.json` / 字幕 / 显示原文都不读这个字段 ✓。
3. 合成 + ASR 端到端验证 `[已实测]`（`ab3\probe\asr-namefix.json`）：
   ```
   旧（ja 原文 牧瀬紅莉栖）      -> はじめまして。巻きてくれないリスミかよ。名前間違えないで。   ← 错读复现 ✓
   新（ttsJa = 牧瀬クリス）      -> はじめまして。マキス、クリスよ。名前間違えないで。           ← 读成「マキセ・クリス」✓
   ```
   产物：`ab3\rep-name-old\`（旧）与 `ab3\rep-name-fix\`（新）。
4. ②**userdict 根治路线**：J 试写 13 列被接受但 `g2p` 返回空串，列格式未核对对 ⇒ 保持 `[待核对]` ✗，本轮**不采用**，先走①假名兜底 ✓。

## 9. 推荐（含理由）

**推荐：继续用 v3（现行 v3 权重 + 现行后处理口径），本轮不换模型；两处按需增强。**

| 结论 | 理由（客观证据） |
|---|---|
| **不换 v2Pro** ✗ | ①**会念丢内容**：12 句平均 CER 0.1228（v3 0.0235），`greet_first` 丢 22 字、`fallback_offline` 丢 15 字（§4.2）②**用不了情绪参考**（上游 v3 专属，§3.1）⇒ 换了等于同时丢掉"更柔的 shy/更失望的 disappointed"这条增强路。③它唯一赢的是速度/显存/体积（RTF 0.316、显存 1291 MiB、体积 −8.3%），但**快和省不该拿语义完整去换** ✗ |
| **v2ProPlus 暂不评价** `[待核对]` | 没有权重文件，**没测过**（§1）——不凭文件名或样本猜它更好 ✗。要结论就得先给两份权重（`kurisu_v2proplus-e100.ckpt` / `kurisu_v2proplus_e12.pth`）。 |
| **人名句立刻用假名兜底** ✓ | `ttsJa = …牧瀬クリスよ…` 后 ASR 从「巻きてくれないリスミか」变成「マキス、クリス」（§6）；显示原文/字幕一字未改 ✓。**这是本轮唯一"确定变好"的改动。** |
| **情绪路由按需开**（建议 ≤3~5 句，如 greet_* 用 shy、fallback_* 用 disappointed）✓ | 只有 v3 能做（§3.1）；实测时长的确会变（shy 版 greet_first 快 0.995s），响度极差 0.31 LU 仍 ≤0.5 ✓。**是否更好听由站长听**（我听不了 ✗）。 |
| 若想再压体积 | v2Pro 的体积优势（−8.3%）可以靠**只对长句降码率**或改用更细分的情绪参考来近似，**不建议因此换模型** ✗ |
