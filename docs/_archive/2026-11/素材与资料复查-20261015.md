3. **时长口径**：`idle` 一律 **510 ms**（3 帧 / 5.88fps），`speaking` 是 **2040 / 3060 / 5100 ms** 三档，帧率一律 **≈24fps**。

4. **`sided_thinking` 有 `speakingAlternate`**（74 帧 / 3060ms，与 `speaking` 的 123 帧 / 5100ms 不同）

5. **图集规格可精确复算**：`size=132`（单元）、`columns=8`，`sequence` 是帧索引数组。
