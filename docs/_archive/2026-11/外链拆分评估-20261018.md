## 4. 门禁判据同步（这是本次唯一"改了判据"的地方，逐条写清为什么）

**⑫ 版式/比例硬约束（9 条）**：判据语义、条数、报错文案一字未改，只把**检索面**从
「`ai/index.html` 这一个文件」换成「`ai/index.html` + 该页 `<link>/<script>` 真实引用的外链资产」
（新增 `asset_corpus()`）。理由：这 9 条 grep 的是 `aspect-ratio:284/600`、`min(300px,44vh)`、
`__xkPhoneAnim`、`xk-emote-ready`、`xkEmoClean` 这类**代码存在性**，代码本身没变、只是换了载体；
不改检索面就必然假红，而假红会倒逼"把内联加回去"——那才是真退化。代码真丢了照样红。

**⑬ 新页产物契约（5 条）**：原判据 `字节数 > 100000` 换成两条：
- `> 8000 字节`（骨架下限）：只剩骨架时约 4–6KB，真实内容页最小 14075B；100000 这个数当初只是
  "真实产物约 15.5 万字节"的侧写，它的前提正是外壳内联，外链化后**前提消失**。
- 页面里必须有 `/css/xk*.css` 与 `/js/xk*.js` 引用（各 ≥2），证明 layout 链没退回到整段内联。
`data-xk-ssr` 判据原样保留。

**⑭ 新增「外链共享运行时」（23 条）**：
- 10 页 `HTML ≤ 90000 字节`（改后最大 61606，留 ~28KB 余量）——防内联回归；
- 每页实际引用的 `/css`、`/js` 逐个 `stat` 必须存在——`resources.Get` 路径写错时 Hugo 静默吐空引用；
- 每个外链名必须匹配 `\.min\.[0-9a-f]{64}\.(css|js)`（白名单：`static/` 下手写且历史上无指纹的
  `xk-saver.js`/`xk-realtime.js`/`xk-app.js`/`phone-emote.js`/`kurisu-player.js`）——没指纹等于改内容
  不改 URL，比内联更糟；
- 三个内容页断言「外壳 `<script` 恰好 2 处且都带 `src`」（运行时 + scene-js）。
  ★"2"这个判据的出处：`_dev/gen-demo-pages.py:114-116` 对**输入源** `docs/demo-内容页外壳.html`
  断言 `len(re.findall(r'<script[^>]*>.*?</script>', shell_body)) == 2`（那是源文件检查，没改也没触发）；
  `assert-build.sh` 与 `_dev/check-ssr-contract.py` 原本都**没有**产物级 script 计数断言，
  所以本次把这条补成产物级硬约束 ⑭ 末尾 3 条。

   与产物已经分叉，但它不进站点主链；后续要么改成引用外链，要么在文档里标成"离线预览件"。
3. `scripts/asset-version.py` 仍会给已带指纹的 URL 再追加 `?v=<sha8>`（实测不会叠加成 `?v=a?v=b`，
   只是冗余）。留着无害；想更干净可以让它跳过 `.min.<64hex>.` 形式的文件名。
