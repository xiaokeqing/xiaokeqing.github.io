**硬要求**
1. `.mod-hd .tag` 里必须是**端点名**（`/overview`、`/audit`、`/api/public/*`）——`markStale()` 靠它匹配 `staleUsed` 打"上次数据"角标（`api-bind.html:130-159`）。
2. 类名只用既有体系（`.mod/.mod-hd/.mod-bd/.k/.tag/.kv/.na/.tb`），**不得新增配色/字体/背景**。
3. 占位初值统一 `—`；需要骨架的慢端点才加 `.sk`（`geo/webstats/alerts/audit`；`overview` 属快端点，不加）。
4. 公开面**不得出现 `NOT_WIRED`**；取不到写「读不到 + 原因」。

## 四、数据来源与字段映射

> 站点线现成工具（不要再设计）：`pick(parts,name)`（本次值优先→上次值兜底，自动记账）、`txt(el,s)`（写值并摘 `.sk`）、`fmt()`、`NA`、`clockOf(ms)`、`maskIp()`、`maskText()`、`errText(parts)`、`errShort(parts)`、`staleNoteInto(host,at)`、`syncAgeText()`。
> `parts` 元素形状（`settle()` 产出，`api-bind.html:180-188`）：`{ path, ok, d, err, stale, staleAt, staleD }`。

### 4.1 接口健康 ← `parts` 全体（无需新请求）
- **注意**：`parts` 现在**不记录耗时**。两种做法（选一，写进本批说明）：
  - (A) **只报状态**（零改动）：列出白名单端点 + `ok ? '正常' : '读不到/HTTP xxx'`；
  - (B) **补耗时**（推荐，成本极低）：在 `settle()` 里加 `var t0 = performance.now(); … ms: Math.round(performance.now()-t0)`，并把它带进 part 对象。
- 白名单（公开只读 GET，实测 9 个固定路径）：`alerts / audit / geo / webstats / honeypot / overview / kb / stories / latest`。
- 口径：**不得使用 `/api/health`**（它返回构建指纹与内部信息，站主已定"不展示"）。
- 一行格式：`<li><span class="k2">/alerts</span><span class="v">正常 · 128ms</span></li>`。

### 4.2 部署可追溯 ← `pick(parts,'overview')`
| 显示 | 字段 |
|---|---|
| 数据快照时间 | `overview.snapshotAt` / `generatedAt` 一类真实时间字段（取不到写 `读不到`） |
| 缓存窗口 | `overview.cacheTtlSeconds` 或响应头口径（如有） |
| 数据源 | `overview.dataSource.wazuhMode`（实测 `REAL`） |
| 节点 | `overview.nodes[]` → **只渲染 `id` / `label` / `online`** |
| ★禁止 | **不渲染 `nodes[].detail`**（实测里面带构建提交号 `build da9d1dba…`）；**不读 `/api/health`** |

### 4.3 处置运维 ← `pick(parts,'audit')`
| 显示 | 字段 |
|---|---|
| 四个计数 | `audit.summary.*` —— **缺一个写一个"读不到"**，绝不补 0 |
| 封禁明细 | `audit.blocks[]` → `maskIp(b.ip) · b.source/actor · b.durationMinutes`（时长缺写"时长读不到"） |
| IP 口径 | 按后端 `ipDisclosure` 脱敏；自由文本里 IPv4 过 `maskText()` |
| 空态 | `blocks=[]` ⇒ 写**"本窗口没有封禁记录（不是取不到）"** |

### 4.4 AI 质量（本次不做，只留位）
- 数据来自评测线 C5（`scripts/eval/`，自用池 ≥96 轮/臂）。**数据到之前该 tab 不出现**（不要写 `NOT_WIRED`）。
- 结构：与其它 tab 同构，`<button data-tab="aiq">AI 质量</button>` + 视图体 `<div class="ops-tab" data-pane="aiq">`，并加注释 `TODO(C5)`。

## 七、已知风险

1. **首屏预算**：`/alerts/` 首屏预算余量不大；三卡若在「数据统计」tab 内且默认不激活，则不计入首屏 —— 施工时确认 tab 切换是 CSS/JS 显隐而不是全量渲染。
2. **`.mod` 依赖**：`markStale()` 按 `.mod` + `.mod-hd .tag` 找卡；结构必须严格照 §三，否则"上次数据"角标不会出现（B2 首版就在此差了一个前导斜杠）。
3. **耗时字段**：`parts` 目前无 `ms`；若选 4.1-A（只报状态），「接口健康」就**不能**展示毫秒 —— 不许编一个假耗时。
4. **不要动 `/test/` 的 ③ 块行为**：迁出后 `/test/` 的 ③ 块收缩成"已迁出到监测中心"的说明即可，别删它的探针（实验台仍要能复现）。
