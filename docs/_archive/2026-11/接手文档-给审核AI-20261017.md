## 2. 架构一句话

浏览器访问 `xiaokeqing.cn`（Cloudflare → srv2 上的 nginx 静态站）；

后端再往下接：Wazuh/Suricata 告警 → 聚合缓存 → 只读别名 `.js`（边缘可缓存 300s）；
问答走 DeepSeek 模型 + 本地知识库检索（RAG）。

**角色（桐莉栖 / Amadeus）全部是本地资源**：立绘 WebP、E-mote 动作模型、预录语音 m4a/webm，不依赖任何在线语音服务。

## 3. 公开面契约（`/api/public/*`，匿名可访问，只读）

| 端点 | 语义 | 关键约束 |
|---|---|---|
| `/api/health` | 后端自述（buildSha、md5、uptime） | 不脱敏但无业务数据 |
| `/api/public/home.js` | 主页聚合（首屏只发 1 个请求） | `x-data-source`、`cache-control: max-age=45, stale-while-revalidate=90` |
| `/api/public/alerts` `/geo` `/overview` `/webstats` `/stories` `/audit` `/deploy` | 监测中心各块 | IP 一律掩码（`1.2.3.x`）；只给结构与计数 |
| `/api/public/kb` | 知识库只读检索 | 20 次/分钟 |
| `/api/public/ask` | 公开问答 | **6 次/分钟/IP**；输出护栏 + 引用 + state 标注 |
| `/api/public/tts` | 在线合成（Fish Audio） | **默认关闭**，调用返回 503 `TTS_DISABLED` |

四条纪律（审核重点）：
1. **匿名路径不得触发处置**：公开面只能解释概念，处置动作在 `/api/response/**`（管理员 + 人工审批）。
2. **IP 打码在服务端做**，前端拿不到原值；请求原值只留在 srv1 日志。
3. **失败要说失败**：取不到就返回错误态，前端显示「读不到（原因）—— 不补数」，绝不编数字。
4. **不匿名常驻**：公开面不提供长连接/SSE，一次性返回。

## 5. 站点实现要点（审核常问的"为什么这么写"）

1. **首屏 3→1 个请求**：`_dev/gen-demo-pages.py` 里 `BASE_JOBS = SSR === 'monitor' ? ['home'] : []`，
   首屏只拉 `home.js` 聚合，失败才回落三端点。实测线上只有 `home.js` + `/api/health` 两个 XHR。
2. **懒加载**：切到某个 tab 才请求对应端点（未切 = 「取数中…」）。面板上会写明"标'本次未发起'的是按 tab 懒加载的"。
3. **数据统计拆 3 个子分区**（概览 / 处置留痕 / 部署与接口），子导航挂在顶栏同一行右侧，
   目的是**一屏不滚动**（1422×744 实测 `.scrollHeight === innerHeight`）。
4. **手机端**：`.stage` 等比缩放（`width:min(262.5vw,302.1vh)`），CRT 始终 92vw 且与底图电视对齐；
   角色面板在窄屏退化成右下 74px 静态立绘条，点开居中放大（同一张 poster，不加载 E-mote 省内存）。
5. **手机内存兜底**：E-mote 只在 ≥1280px 挂载；模型 ready 后加 `html.xk-emote-ready` 才撤掉垫底立绘
   （否则会出现"两个人在屏上"——这个 bug 今天修过一次，根因是缓存命中时 `onStatus('ready')` 早于回调注册，改成 400ms 轮询 `em.status()`）。
6. **省流模式**：`static/js/xk-saver.js` 按 `navigator.connection`（saveData / 2g）判定，只加载背景不加载角色；
   想绕过加 `?xk-saver=0`。**注意**：桌面 Chromium 的模拟弱网也会触发，容易被误判成 bug。

## 6. 语音与角色（站主今天追问"是不是接的 deepseek API"，答案见下）

- **聊天回答**：DeepSeek 模型（走后端 agent 链路），文字。
- **角色说话**：**预录音轨**，不是实时 TTS。`static/kurisu/voice/bank.json`（当前 162 条），
  每条含：中文文本、分组（greeting / page_intro / status / fallback / faq / idle_banter）、
  `audio`（m4a）、`audioSources`（m4a+webm）、`envelope`（10ms 粒度 RMS 包络，驱动口型）、`sha256`、时长。
- **音轨是怎么产出的**：本机 GPT-SoVITS v3（`E:\DeepSeek1\work\_amadeus-src`，RTX 3060），
  `scripts/voice/synth.py --mode one --lines <json> --lang 日文 --emotions on --cuda` → `build_bank.py` → 合并进 `bank.json`。
  本轮 rev4 重录了 8 条（首访自我介绍 + 四个模块介绍 + 两次回访），时长 0.75s–21.36s。
- **口型**：`static/js/kurisu-player.js` 用 envelope 推 `mouthValue`（0.08 以下算静音），
  所以字幕与嘴型是**同一份时间轴**，不靠猜。
- **在线 TTS 通道存在但关闭**（Fish Audio，`app.tts.enabled=false` → 503）。
- ★ 因此「语音不够智能」是结构性的：**她说的话来自固定台词表，不是模型现生成**。
  要让问答回答也出声，需要把在线 TTS 打开（有成本/延迟）或扩台词表（只能覆盖固定场景）。
