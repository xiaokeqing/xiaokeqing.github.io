## 1. 一句话定位

```
**AI 驱动的安全数字人**：真实攻击数据 → LLM 理解与决策 → 数字角色用语言 / 表情 / 动作表达出来。

不是"博客里放了个会动的动漫人物"，也不是"套壳 ChatGPT"——
数据是真的（两台服务器上跑着自己的蜜罐与检测栈）、语音是自己合成的（日语、本地克隆音色）、
行为是状态机 + LLM 决策驱动的、边界是把 LLM 人格层与安全执行层做了权限隔离的。
```

**四层齐全**（评审最认这个结构 ✓，出处 `docs/AI项目升级方案-20261015.md` §0）：

| 层 | 一句话 | 状态 |
|---|---|---|
| 数据层 | 真实攻击日志 / 蜜罐凭证 / 地理富化 / 攻击故事线（别处没有的独特语料 ✓） | ✅ 生产运行 |
| 推理层 | RAG 混合检索问答（生产 ✓）+ 事件→行为决策 | 🟡 问答已上线；决策（T14）**未接线** ✗ |
| 交互层 | 日语语音（本地克隆 ✓）+ 帧/视频动画 + 口型 | 🟡 12 句语音已上线；状态机/口型/视频**未接线** ✗ |
| 工程层 | 端侧推理（6GB 跑通 ✓）、成本控制（缓存/熔断/配额）、可复现管线、门禁与原子发布 | ✅ 已建立 |

## 5. 难点与解法（**挑真的踩过的** ✓）

| # | 难点 | 怎么解 | 证据 / 出处 |
|---|---|---|---|
| 1 | **6GB 显存跑通 TTS** | 走 SDPA + **CUDA Graph / static-KV**（CUDA 路径才吃到）；`--lang 日文` 走日语路线**不需要 BERT**（中文路线要 1.2GB 的 BERT，峰值 2647MiB；日语峰值 2084MiB）；实测 torch 峰值 2070MiB | `scripts/voice/README.md` §1、§5.4；`docs/总账…` §2.4 |
| 2 | **透明视频只有 VP9+alpha 可行** | B3 双拼 mp4（yuv444/420）alpha MAE 0.69~1.05，比 B 路线差 3.7~5.6×；AV1+alpha 在 Chromium 透明解出率 0.0% ⇒ 定 **VP9+alpha**（并写死色彩标记、以实际码流尺寸为准） | `docs/总账…` §2.3；C8 |
| 3 | **新素材包几何是 0.738× 居中裁窄** | 33/40 剪辑从 1028/764 原始画幅裁到 500~636 宽（`idle_closed_eye` 960→904）⇒ **不 pad 会横向偏 9.5%** ✗ ⇒ 转码前统一 `pad=764:1028:100:0:black`；对齐工具用"目标剪辑/同族锚点"而不是全局中位数 | `docs/总账…` §2.1；`docs/素材产线能力-T18…` §2.3 |
| 4 | **未备案 ⇒ 境内直连被阻断** | 铁证：`curl -H 'Host: xiaokeqing.cn' http://{公网IP-腾讯云}/` → **302 → dnspod.qcloud.com/static/webblock.html**，443 直接 reset ⇒ 改走 **Cloudflare 隧道**（出站）→ srv2 `127.0.0.1:18080`；代价是 CF 链路慢，**唯一解是备案** | `docs/总账…` §2.5；C1 |
| 5 | **fail-closed：检索不到就说没依据** | 把"不许假数字"从口径变成**可自动判分的用例**：40 题里 19 条应拒答，`must_not_contain` 放真实快照数字（编出来即判幻觉）；`state=input-insufficient` / `rule-based` 都是正确拒答态 | `docs/评测报告…` §3.1、§3.3 |
| 6 | **人格层与执行层权限隔离** | 人格层只读 + 只提议；执行入口只有技能层能调且必须带审批凭证；`publicDemo=true` + `toolExecutionAllowed=false`；把"能读/能决定/能提议"穷举成权限矩阵 + 枚举白名单 + 输出净化器 ⇒ 提示词注入只能改变语气、改不了权限 | `docs/双智能体协作规格-20261015.md` §3、§5；`docs/待办…` §3 的接口自述 |
| 7 | **生成器产物纪律** | 五页是 `_dev/gen-demo-pages.py` 的产物 ⇒ **改 `layouts/*` 必须同步生成器** ✗，否则下次跑生成器被覆盖；`_dev/` 在 .gitignore 白名单内 | `docs/项目总体规划…` §2、§6④ |
| 8 | **端口冲突** | srv2 上 `127.0.0.1:443` 归 **wazuh.dashboard 的 docker-proxy** ⇒ nginx **不能绑 0.0.0.0:443** ✗，只能 `10.0.0.10:443` + `127.0.0.1:18080`（隧道回源） | `docs/总账…` §2.5 |
| 9 | （备选）**包络必须用 C 实现** | 自写浮点 RMS 与既有 12 句包络**逐点不一致**（364 点里 165 点不同，近静音窗 1e-4 就差翻 `round(...,4)` 的边界）⇒ 必须用 `audioop.rms`；Python 3.13 移除该模块，届时需换实现并重对齐 | `scripts/voice/README.md` §5.5 |
| 10 | （备选）**ffmpeg 子进程写仓库目录 EACCES** | python/PowerShell 能写、**ffmpeg 不能** ⇒ 产物一律落仓库外，确认后再拷进 `static/kurisu/voice/` | `scripts/voice/README.md` §5.7；`docs/评测报告…` F5 |
