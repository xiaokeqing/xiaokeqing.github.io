## 一、方向一句话

**这个站不缺配色，缺"光"。** 暖灰玻璃 + 青色终端 + CRT 桐莉栖是品牌资产，不动配色；只做一件事——给 UI 补一套统一的"光与材质"：让卡片从"平的深色块"变成"顶部受光、上亮下暗"的玻璃，让顶栏变成真正的毛玻璃。

## 三、为什么是这些值（设计判断）

- **顶部高光渐变 .18~.20**：在深色卡片上正好是"一眼可见但不过曝"的受光档；低于 .12 肉眼几乎无感（试过，站主反馈"没区别"）。
- **顶部描边 .40~.45**：玻璃拟态的标志性"亮边"，深底上清晰可见。
- **底部压暗 rgba(0,0,0,.16~.30)**：形成"上亮下暗"的立体感，是"平"和"立体"的分界。
- **磷光 .22~.38**：呼应 CRT 辉光钟的发光质感，只给关键数字，不做满屏霓虹。
