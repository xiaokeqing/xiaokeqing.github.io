## 三、今天踩过、明天别再踩的坑

1. **Hugo minify 会改名 JS 标识符**：`public/*.html` 里 grep `bindBans`/`settleHome` 全是 0，不代表没渲染。验证前端逻辑只能靠 DOM 行为或临时标记变量（`window.XK_MARK_TEST=1`）。
2. **nginx `add_header` 不可继承**：location 层只要有 `add_header` 就覆盖 server 层 ⇒ 安全头必须写进每个 location（现写在 `location /`）。
3. **切屏瞬间量尺寸必然为 0**：任何 canvas/图表初始化都要带「量不到就重试」+ 切 tab/hash 重踢，不能只靠 `IntersectionObserver`（`display:none→block` 不保证触发）。
4. **云镜路径白名单含 containerd 快照号**（`snapshots/1057/…`），容器重建即失效 ⇒ 用 MD5。
5. **PowerShell 5.1 读无 BOM 的 .ps1 会乱码** ⇒ 脚本保持 UTF-8 BOM + CRLF；避免嵌套 `$((git …).Trim())`。
6. **发布链产物已在 `~/.xk-deploy/`**，不要在 `/tmp` 里放脚本（云镜会把 `/tmp/*.sh` 报成恶意文件）。
