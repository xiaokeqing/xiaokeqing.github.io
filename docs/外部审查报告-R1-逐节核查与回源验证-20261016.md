### X1 【P0 · 硬伤】状态机 38/38 个节点的嘴部补丁路径 **100% 断链**

```
证据（[R1实测]）：
  statemachine.json 每个 node 的 mouthPatch.file 形如   idle.patch.png
  static/kurisu/mouth/ 磁盘实际文件名形如                 idle.patch.webp
                                                        idle.closedRegion.webp
                                                        idle.json
  → 38 个引用，命中磁盘 0 个；extensions 全部是 .png vs .webp
```

- 磁盘 `mouth/` 只有 **16 组**（48 文件 = 16 剪辑 × 3 文件），与 `has_mouth_profile=true` 的 16 个节点一一对应。
- 也就是说：**只有 16 个剪辑有真实嘴型补丁素材，其余 22 个节点的 `mouthPatch` 是指向不存在文件的"假路径"**。
- **为什么严重**：详版 §⑨ 把 `T8 状态机 + 口型接线`列为"正在做 / 最难"。一旦接线完成，玩家游走到这 22 个节点时嘴部补丁层会 404，
  表现为**嘴不动或嘴部贴图缺失**——而这个 bug 在项目内部的 26 条"未添加功能"清单和 9 条"工程债"里**都没有条目**。
- **同时违反 D4**：`mouthPatch.file` 指向一个不存在的文件，属于"写了一个看起来有用的假值"，与"取不到就写读不到"的口径相反。
- **建议修法**（两条都要）：
  1. 有 profile 的 16 个节点：`mouthPatch.file` 的 `.png` → `.webp`（并同步 `closedRegion` / `json` 三个文件）；
  2. 其余 22 个节点：`mouthPatch` 显式置 **`null`**，让播放器走"无嘴部补丁"降级，而不是去请求一个 404。
- **并把它做成门禁**：新增资产引用完整性检查（本轮已落地脚本，见 §4）。
