### 4.3 剥壳模板（"固定抬头 / 引用尾"的物理依据，**逐条带出处**）

§10.1 要求"先去掉回答里固定的抬头与引用尾"，但**没说模板长什么样**。本脚本不猜：把后端拼答案时**写死的字符串**

| `## 研判结论`、`## 取证发现`、`> 证据采集方式：…`、`### 证据解读` | `:710/727/733`、`:1187`、`:1188`、`:1192` |

| `## 知识库参考（未经 AI 加工）`、`> 结论生成方式：…`、`> state=…`、`⚠️ 注意：…` | `:714/730/737`、`:505/1194/1357`、`:485/514/540/944/1358`、`:1392` |


即**评测身份的"处置结果"模板正文逐字相同**（护栏命中 ⇒ 同一条模板），不是模型在复读 ⇒ 才有 §5.2 的 `D2=0`。

### 5.5 基线结论：**不可作基线**（照纪律明说，不编数字 ✓）

脚本自动给的判据（`baseline.eligible`）三项全部不满足：

```
· 数据里没有任何会话标识字段（conversationId/sessionId）⇒ 只有批次/文件级**伪会话**，不是 §10 定义的「同一会话」
· 真会话数 0 < 3（§10.3 要求先补 3~5 条多轮题）
· 真会话最长仅 0 轮（无多轮会话）
```

⇒ **§5.1 的三个数只能当"量级参考"，不能当验收基线，也不能与上游 0.47 直接比**（上游是**同一条会话**里的口头禅计数）。
D1 高达 0.61 也**不是**"模型在复读"的直接证据：它主要来自"同一批里连续几条同 topic 的答案开头一样"

也说明**没有多轮题时这条指标会系统性失真**。

**要拿到真基线，必须先做（不在本件做 ✗）**：按 §10.3 补 **3~5 条多轮题**（会话 ≤17 轮），
在采集记录里带上**会话标识**，再跑同一个脚本（那时 `baseline.eligible` 会自动变 true 并报 Wilson CI）。
