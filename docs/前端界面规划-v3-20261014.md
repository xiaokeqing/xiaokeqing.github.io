## 1. 信息架构（功能归拢）

"杂七杂八的功能"归拢为 **5 个内容页**，全部套统一外壳（§2）：

| 路由 | 收拢的内容 | 数据来源 |
|---|---|---|
| `#/home` | 视频样式场景（冻结） | overview / ask |
| `#/monitor` 监测中心 | **控制台总汇**：24h 指标带、告警流、蜜罐凭据结构、地理 TOP、攻击故事线、访问统计 7×24（原散落各处的数据块全部收进这一页的分区卡片） | overview / alerts / honeypot / geo / stories / webstats |
| `#/ai` AI 问答 | 对话 + 六态口径卡 + 限额卡（**保留**，闸门断言依赖其 id） | ask / kb |
| `#/notes` `#/note` | 笔记流 + 单篇阅读（read 阅读主题） | Hugo content |
| `#/range` 靶场 | 原表单内容，套终端卡片样式 | 既有端点 |
| `#/about` 关于 | 站点口径、红线条款 | 静态 |

不再单设"大屏/故事线/蜜罐"等独立路由——它们成为 monitor 里的卡片分区，导航只剩 6 项，左侧导引栏一屏放下。
〔现状〕这些 API 与页面元素都已存在，本规划做的是**排版归拢**，不改数据链路、不新增端点。
迁移代价提示：125 项 CDP 验收里有"三栏契约/口径卡 id"类断言，归拢时需逐项核对选择器，预期要同步改 `_dev/verify-redesign.ps1`。

## 2. 统一内容页外壳（站主 2026-10-14 看演示后修订：浅色主题版）

### 2.1 栅格与导航（修订）

- **导航统一为顶部横向 pill**（站主拍板：不要一横一竖两种）；左侧竖排导引栏**取消**。
- **整体回暗、与主页同一套 token**（站主二次拍板：浅色与主页配不上）：`#0B1118` 底、青 `#39D0D8`、
  玻璃面板——与 demo-主页.html 完全同源。
- **内容页背景用素材包的空房间图**（`_kurisu-full\web\scenes\BG_empty.webp`，84KB）：
  固定铺满 + blur 22px + brightness .30 当氛围底（图自带 CRT 边框，模糊后成为暗角，正合适），
  零新增资产。背景候选也可换 computer_use / stand_thinking 等场景图，同一处理管线。
- 导航浮条与主页同款（顶部居中横排 pill）；HOLO 面板在**右上角**（左上角让位给导航）。

### 2.2 monitor 分区排版（修订：一整块"大屏幕"）

全部模块收进**单个 `.screen` 大屏容器**（站主拍板：功能集中到一块、模拟大屏幕）：
大屏标题栏（`● XK-LAB · SEC-CONSOLE` + 口径 + SYNC 时间）→ 内部模块网格：
指标带 4 列 → 告警|蜜罐（2:1）→ 地理|故事线（1:2）→ 7×24 通栏。

### 2.3 右侧 HOLO 人物面板 → 左上角 HOLO（修订）

位置 left 16 / top 62，宽 284，可折叠为头像泡（左上）；其余规格（头像 canvas 雪碧条、
说话行、波形、情绪圆点、ask 联动）不变。

### 2.4 AI 问答（修订：纯对话）

照站主参考图简化为**纯聊天**：消息流（AI 左 / 用户右气泡）+ 底部圆角输入条 + 发送键；
状态徽标与额度收进聊条头一行；预设 chips、两块口径卡**从 AI 页移除**（口径内容并入
关于页，限额在聊天头一行展示）。对话区占满视高，引用卡片内联在消息里。

## 3. 主页（冻结 + 仅收口）

主页维持录屏效果，不做重新设计。只保留 v2 的收口项：

1. 开场 84 帧（2.8s，眨眼覆盖）+ **会话级只播一次** + hi 图集 load 事件后再加载（v2 §2.4 / 挑战①）；
2. 开场→中景允许一次 0.35s 线性 alpha 交叉（标注"属我方扩展"）；
3. 层序 / CRT 定位公式 / 对比度规格 / 屏内元素 → 直接沿用 v2 §2.1–2.3，不重开讨论；
4. 主页**不挂** HOLO 面板（她有 CRT，不需要第二个分身）；
5. **主页无底部输入条**（站主 2026-10-14 看演示后拍板）：问答统一入口在 #/ai，
   主页只留场景 + 屏内状态行/字幕条 + 导航。原 v2/全景文档"底部输入条"口径作废。

## 5. 状态与降级 / 资产 / 可访问性 / 验收

- **降级**：全部沿用 v2 §4，追加两条——面板数据取不到 → 说话行显示"读不到"；`kurisuEnabled=false` 时外壳里面板整块不渲染（含折叠泡）。
- **资产**：外壳零新增（avatar 图已有 1.6MB）；HOLO 面板每页只载当前情绪的 2 张图（132px 静帧 ≈10KB 或雪碧条 ≈100-200KB，懒载）。
  **修正 v2 §5.2 的判断**（依据 `_kurisu-full\web\` 实量）：medium 分档 35 件/34.6MB 已覆盖全量剪辑，
  + boot 6.7 + poster 1.9 + scenes 0.6 + mouth 0.5 + meta ≈ **45MB**。
  ⇒ 不需要"精选 10 剪辑"折中：**39 剪辑全量直接发 medium 档，总量上限改 48MB**，状态机完整 alive；
  hi 档（atlas 143MB）不进仓库，将来按需单剪辑升级。头像素材语义勘误（本版新增实测）：
  `avatar\*.static.webp` = 132×132 单帧（DOM 直接用）；`*.idle/speaking.webp` = 132×132 单元、
  8 列雪碧条（**必须 canvas 切帧，禁止当 img 直接用**，v1 演示踩过此坑）；`full\` 同理。
- **可访问性**：面板是功能组件不是装饰——`role="complementary"` + `aria-label="助手面板"`；说话行 `aria-live="polite"`；头像 `alt="桐莉栖"`（唯一有 alt 的角色形态，因为这里有真实文本职责）；折叠按钮有 aria-expanded。
- **验收（在 v2 §7 清单基础上追加）**：
  - [ ] F1 三视图（monitor/ai/notes）5 视口截图，主区内容与面板**零重叠**（求交脚本）
  - [ ] F2 面板折叠/展开两态截图 + localStorage 记忆复现
  - [ ] F3 情绪自动切换：ask 在飞→思考头像、返回→speaking 头像截图对
  - [ ] F4 API 断开时面板显示"读不到"截图
  - [ ] F5 首屏两实数：内容页 ≤800KB（外壳+面板头像），monitor 因图表库零新增不变

## 6. 对现状的三处挑战（修订版）

1. **AI 页专用 320px 固定右栏 → 全站统一 HOLO 浮动面板。** 固定栏挤占对话宽度、且只有 AI 页有"她"；
   浮动面板全内容页复用、可折叠、不占栅格。代价：删 xk-portal--ai 的栅格特例，闸门三栏契约断言要改。
2. **情绪 8 按钮的调试面板属性 → 缩成 11px 圆点行收进面板底部。** 能力保留、视觉退出主层；
   默认仍随对话自动切换。代价：近零。
3. **数据块散落多页/多处 → monitor 单页分区总汇。** 减少导航项与重复样式，故事线/蜜罐/地理等
   强关联数据同屏互证。代价：一次性排版迁移 + 验收脚本同步改（最大工作量在这）。

## 7. 如果只做三件事

1. **HOLO 浮动面板组件**（§2.3）——这是本次的核心交付，先做它，三页立刻统一；
2. **monitor 分区总汇排版**（§2.2，照演示图施工）——"杂七杂八归拢"的主体；
3. **39 剪辑 medium 档全量上线（≈35MB，总量上限改 48MB）**（§5）——状态机完整 alive，
   不再需要精选折中；hi 档 143MB 留将来按需单剪辑升级。
