### 1.1 契约本体

**落点：`POST /api/public/ask` 响应体的 `data.decision`**（与 `state` / `outputFindings` **同一个信封**，不另开通道 ⟹ 前端只读一次响应就够 ✓）。

```jsonc

  "emotionFrom": "normal",          // 8 类之一；= 上一次 decision 的 emotionTo（黏滞）；首次/无历史 = "normal"
```

**字段判据表（实现与验收共用，不许各自解释）**

| 字段 | 类型 | 值域 / 白名单 | 缺失或非法时**必须**怎么回退 | 前端消费点 |
|---|---|---|---|---|

| `emotionFrom` | string | 8 类 | 非法 ⇒ 取**本地黏滞值**（前端 `window.__xkEmo.emotion`）；本地也没有 ⇒ `normal` | 仅用于 HUD/审计（`emotionFrom → emotionTo` 展示） |
| `emotionTo` | string | 8 类 | 非法 ⇒ `normal` + `fallbackUsed=true` | `XK_SM_JS.host('emotion', …)` 或 `xkmSetEmotion()` |
| `action` | string | 38 剪辑名（`clips_not_in_graph` 的 `sad`/`smile` **明确非法** ✗） | 非法 ⇒ 用**情绪→剪辑映射表**（§1.4）按 `emotionTo` 推一个；再不行 ⇒ `idle` | 状态机 `enter(clip)`（`host('emotion')` 内部就是这么选的） |

| `urgency` | number | 0.0~1.0 | 越界/非数字 ⇒ 钳到 `[0,1]`；缺失 ⇒ `0.5` | 表情强度 / 是否打断当前动作 |
| `reason` | string | ≤200 字符 | 超长 ⇒ 截断；缺失 ⇒ `""` | HUD 一行（**先脱敏**） |
| `citations` | string[] | ≤8 条，每条 ≤200 字符 | 非数组 ⇒ `[]`；超限 ⇒ 截断 | 与既有引用卡片同源展示 |

> 收在一个 `decision` 对象里 ⟹ **一个字段一个来源**，前端只需判 `data.decision` 是否存在 ✓。

| 语义 | 官方口径 | 本契约字段 | 取值来源 | 黏滞（sticky）规则 `[建议]` |

| 用户情绪 | `[your emotion → …]` 的左边 | **不设**（公开面只有一个匿名访客问句，情绪识别不可靠 ⇒ 不做 ✗） | — | — |
