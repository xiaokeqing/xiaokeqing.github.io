## ⑪ 踩过的坑大全（现象 → 根因 → 修法）

1. 发布成功但线上没变 → 幂等只比 `index.html` ⇒ 纯资源发布被判"无变化"并 exit 0 → **改整树内容哈希**
2. 上线音频真峰超标（最差 −0.37 dBTP）→ 只保采样峰 + LUFS 在 fade 前测 → **母带限幅 + 编码后实测 + 补降**
3. 表情演错但不报错 → 宿主情绪名不在清单 ⇒ 静默兜底 → **别名适配 + 构建期断言**
4. 眨眼数字全绿但屏幕上不可见 → 眼皮补丁文件名与契约不符（404）→ **改名 + 同帧像素 A/B 验证**
5. 状态机 4 条新边被静默丢弃 → 守卫比错键（边端点名 vs 节点 id）→ **改比 `clip` + 非法端点 `raise SystemExit`**
6. 生成器"跑过了"但文件没变 → GBK 控制台 `UnicodeEncodeError` 崩在写盘前 → **强制 UTF-8 stdout**
7. 手机底部导航点不到 → `.ai-grid` 两列把布局视口撑到 620px ⇒ `fixed` 导航算出 top=1286 > 812 → **窄屏单列 + `min-width:0`**
8. 手机脸空白 → iOS 内存压力丢弃 34~53MB 图集位图 → **手机不拉 hi（`hiFree`）+ 解码失败重试/降档**
9. 手机"糊" → 源单元 321~380px 被画到约 800×1000 物理像素（≈2.5× 上采样）→ **小档 + 视口自适应（待拍板）**
10. 行数量错 → `Get-Content`/`Measure-Object -Line` 对 LF/UTF-8 会少算 → **`ReadAllText().Split([char]10).Count - 1`**
11. 远程命令炸/误报 → PowerShell 引号坑（`\n`、嵌套引号、`$( )`）→ **payload 走 base64 或文件；命令用单引号整条**
12. `.ps1` 语法炸 → 丢了 **UTF-8 BOM**（PS 5.1 按 GBK 读）→ **保留 BOM**；`.sh` 不许有 BOM
13. 发布整树哈希双侧不一致 → Linux `sort` 走 glibc collation → **两侧 `LC_ALL=C`**
14. 发布总走不到"无变化"分支 → `index.json` 含构建时间戳 → **忽略该文件**
15. 提交夹带别人半成品 → 共用 git index → **路径限定提交 + 提交前 `git diff --cached --name-only`**
16. 被 fail2ban 拉黑 → 跑了大输出 SSH 命令 + 会话中断 → **`--tail`+截断；解封走 VNC**
17. 子代理把文件写到仓库外 → 子代理 cwd 不是仓库 → **一律给绝对路径；要求 `Get-Item` 自证**
18. 前端"花而不清" → 优化偏装饰（浮卡/滚动行/count-up）→ **判断标准：更清楚=好，只是更花=删**
19. CF 注入第三方 beacon → 与"零第三方脚本"冲突 → **CF 控制台 Web Analytics 置 Disable**（已收口）
20. 第三方服务回源拉不到文件 → 走 CF 链路失败（50s）→ **给 `direct.xiaokeqing.cn`**
21. 跨域读不到 `Retry-After` → 非 CORS 安全响应头 → **429 补 `Access-Control-Expose-Headers` 或 body 带 `retryAfter`**
