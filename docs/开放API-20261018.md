## 二、通用约定（先读这一节，能省掉一半疑问）

### 2.1 响应外壳

所有端点的外层统一是 `{code, message, data}`（`/ip/` 页第 212 行原文：

> 响应外层统一是 `{code, message, data}`；缺失项的 `data.*` 是 null，原因在 `data.notes[]` 里逐条写着。

实测 `home`：

```json
{"code":200,"message":"success","data":{"alerts":{...},"geo":{...},"honeypot":{...},"audit":{...}}}
```

`data` 内部各块自带 `generatedAt` / `cacheSeconds`；`home` 另有 `snapshotAt` / `cacheAgeSeconds` / `snapshotTtlSeconds` 包装（见 `docs/攻击地图-可行性评估.md:86` 对 `home.js` 的说明）。

### 2.2 鉴权：零鉴权

公开面全部无令牌。唯一的"特权"入口是 `POST /api/public/ask` 上的可选请求头：

```
X-User-Token: <登录态 token>     # 有效 → 跳过限流；无效 → 照常按访客口径限流
```

命中时响应头回 `X-Owner-Ask: 1`、`X-RateLimit-Limit: owner-unlimited`（`content/posts/public-api-rate-limit-owner-token.md:32`）。**伪造这个头不会放行**——校验复用登录服务。

### 2.3 CORS

`application.yml` 读到的 `allowed-origins` 是 4 项白名单（`https://xiaokeqing.cn`、`https://www.xiaokeqing.cn`、`http://localhost:1313`、`http://127.0.0.1:1313`），自定义头只放 `X-User-Token` 一个。
注意口径冲突：`scripts/assert-build.sh:105` 的注释写 `CORS=*`。**两个来源不一致，本轮未复核响应头，按"白名单 + 单个自定义头"理解更稳**；跨域用不上就老实用 `curl`（不受 CORS 约束）。

### 2.4 缓存语义

| 端点 | `Cache-Control` | 说明 |
|---|---|---|
| 多数 `/api/public/*` | `public, max-age=45, stale-while-revalidate=300` | **本轮实测值**（`home.js` 响应头） |
| `/api/public/stories` | 15s | `/api/` 页：「缓存时长各端点不同（多数 45 秒，`stories` 15 秒）」 |
| `/api/health` | 无缓存（`cf-cache-status: DYNAMIC`） | 每次跨境回源 3–4s，别塞首屏必等路径 |
| `/api/public/*.js` 别名 | 同上，但**可被边缘缓存** | 命中缓存**不到源站**，因此**不吃限流** |

三条纪律：

1. **别名响应仍是 `application/json`**，照常 `res.json()` 解析，不要当脚本执行（`layouts/api/list.html` 写死的契约；一条命令可自证：`curl -s -D - .../home.js | head -c 300`）。
2. **别加 cache-buster**（`?cb=`、`?t=`、`Date.now()`）——每次都是新 URL，100% 回源。
3. `?q=` / `?src=` 这类语义参数是允许的（换来的是不同内容）。

真实年龄 = 响应体里的 `cacheAgeSeconds` + 响应头 `Age`（`layouts/api/list.html`：「快 ≠ 新」）。
口径冲突留档：`application.yml` 里写的是 `cache-seconds: 15`（应用内快照 TTL 同时下发 `max-age`），实测头是 45 / swr 300 —— **以响应头为准**。

### 2.5 限流

| 作用域 | 限额 | 证据 |
|---|---|---|
| 全部公开端点（按 IP，固定窗口，**304 也计入**） | 20 次/分钟 | `application.yml` `requests-per-minute: 20` |
| `GET /api/public/kb?q=` | 20 次/分钟（独立计数，且有 embedding 成本 ⇒ 禁止轮询） | 同上 + `/api/` 页 |
| `POST /api/public/ask` | 6 次/分钟 + 同源并发 1 + 公开池 30 次/日 | 同上 `ask.requests-per-minute: 6` |

超限返回 `429` 且带 `Retry-After`（`content/posts/public-api-rate-limit-owner-token.md:14`）。**429 和"读不到"是两件事**：前者等一会儿再来，后者是数据源没数据。

### 2.6 错误码

| 码 | `message` / `reason` | 出现处 |
|---|---|---|
| 400 | `{"message":"缺少 src 参数（要查哪一个来源）","reason":"MISSING_SRC"}` | `GET /api/public/story` 缺 `src` |
| 400 | `TEXT_NOT_ALLOWED` | `POST /api/public/tts` 塞自由文本（只收 `phraseId` / `textHash`） |
| 400 | `reason`（机读，如非法 IPv4 / 内网地址被拒） | `GET /api/public/ip?q=` 的设计口径（本轮 404，见 §3.18） |
| 404 | `{"code":404,"message":"接口或资源不存在"}` | 不存在的路径；`/api/public/stories/1`（无子资源）；`alerts/{aggId}` 的未知 id |
| 429 | 限流 | 见 §2.5 |
| 503 | `TTS_DISABLED` | `POST /api/public/tts` 默认关闭态 |
| 200 | `available:false` + `reason` | `deploy` / `eval` 的"文件没配好"，**不是接口坏了** |

## 三、逐端点

字段一律取自**已核对过的来源**；文档之间记法有出入的，标「口径冲突」，以 curl 实测为准。

### 3.1 `GET /api/public/home`

- **用途**：首屏聚合——把 `alerts` + `geo` + `honeypot`（近期构建里还能看到 `audit`）三/四合一，把 3–4 个请求压成 1 个。
- **参数**：无。
- **返回**：`data.alerts` / `data.geo` / `data.honeypot` / `data.audit` / `data.ipDisclosure{notice, removalContact}`，外层另有 `snapshotAt` / `cacheAgeSeconds` / `snapshotTtlSeconds`。
- **限流**：20/分钟（走 `.js` 别名且命中边缘缓存时不吃限流）。
- **缓存**：45s + `stale-while-revalidate=300`。
- **已知坑**：**体量不固定**——本轮抓到 7,091 / 21,110 / 43,077 B 三种（聚合块与压缩与否不同），别当固定大小的小接口；`audit` 块在 43 KB 变体里出现过、另两个变体里没有 ⇒ **"home 是否并了 audit/health" 正在变动中，写代码前先 curl 一次**。
- **未实现**：`data.health` 本轮未观测到（把 `health` 并进 `home` 是 2026-10-18 交接里列出的待办，尚未完成）。

### 3.2 `GET /api/health`

- **用途**：进程活着 + 线上跑的是哪个版本（唯一端出构建指纹的端点）。
- **返回**（实测）：`embeddedGitPropertiesPresent`、`buildTime`、`embeddedGitCommitTime`、`fingerprintIssues[]`、`buildSha`、`artifactMd5`、`fingerprintMismatch`、`embeddedGitDirty`、`embeddedGitCommit`、`expectedReleaseCommit`、`vectorStore`、`documentVectors`、`alertsMockEnabled`、`logsMockEnabled`、`uptimeMs`、`status`。
  本轮实测：`"buildSha":"9c738daecbdaa3cc17203b542d576fede4fffc3f"`、`"artifactMd5":"80c425a9079c8e1d3bb5b99143a185f7"`、`"fingerprintMismatch":false`、`"embeddedGitDirty":false`、`"embeddedGitCommitTime":"2026-10-18T01:40:44+0000"`。
- **限流**：不在 `/api/public/**`（CORS 拦截器只挂公开面），但同样吃 IP 限流与 CF。
- **缓存**：无（`DYNAMIC`），每次回源 3–4s。
- **已知坑**：`embeddedGitCommitMessage` 已于 2026-10-16 删除（U5 部分收口），**别按老文档读这个字段**；`documentVectors: 318` 是"向量库恢复对不对"的核对口径。

- **未实现**：无。

- **用途**：单源事件时间线（点了才拉，页面不预取）。
- **参数**：`src`（必填，来源标识；填 `stories` 候选池返回的真实 `srcIp`）。

- **已知坑**：缺 `src` → **400 `MISSING_SRC`**；每段最多 40 条，截断时 `truncated=true` 如实标 —— **别把截断后的时间线当完整攻击过程**；脱敏要连 `events[].summary` 里的内嵌 IP 一起盖。
- **未实现**：无。

### 3.13 `GET /api/public/kb?q=`

- **用途**：知识库只读检索（白名单内）。
- **参数**：`q`（可选；**不带也不报错**）。

- **缓存** 45s。
- **白名单口径（写在响应 `rule` 里）**：根目录 `security-docs` / `data/kb-approved`；来源类型 `community`；`denied-keywords=internal`；top-k=3；摘要 300 字。
- **已知坑**：不带 `q` 时返回空 `results` + `note`「未提供查询词（q）」——**别把这句当检索失败**；检索不到是真没有，不是接口坏了。
- **未实现**：分页 / 无限滚动（top-k 固定 3）。

### 3.14 `POST /api/public/ask`

- **用途**：公开问答（检索 + 引用 + 六态标注）。**只解释、不做任何处置动作。**
- **请求**：`Content-Type: application/json`，body **只有** `{question}`（前端实测逐字 `{"question":"什么是 XSS？怎么防？"}`），可带 `conversationId`（省略则后端生成并在响应里回）。`q` 也接受（`body.get("question")` 为空时取 `q`）。
  约束：`max-question-chars: 600`、`max-body-chars: 4000`、`deadline-ms: 20000`。
- **返回**：`answer`、`state` / `stateLabel`（六态机读值）、`citations[]{title, snippet, sourceType, sourceTypeLabel, trustLevel, trustLevelLabel, score, publicRule}`、`citationsInAnswer`、`quota{pool, limit, used, remaining}`、`clientIpMasked`、`outputFindings`、`generated`、`note`、`ttsTextHash`、`deadlineMs`。
  实测历史值：`quota` 池 `public-demo`，`used=15 / limit=30`。
- **限流**：6 次/分钟/IP + 同源并发 1 + 公开池 30 次/日；超限 429 + `Retry-After`（前端实测读到 7 逐秒递减）。
- **缓存**：POST 不缓存。
- **已知坑**：`clientIpMasked` 已是打码值，**别当原始 IP**；`state=model-failed` 时字幕带 `failureReason` 原话，**不补答案**；公开面结论**不做事件定级**（严重度强制 `INFO`）。
- **未实现**：多轮上下文（除可选的 `conversationId` 外无历史）、工具调用、流式输出（无 SSE/WebSocket）。

### 3.15 `POST /api/public/tts`

- **用途**：在线语音合成代理（转发字节流 + 口型包络）。**默认关闭。**
- **请求**：只收白名单 `phraseId` / `textHash`；塞自由文本 → **400 `TEXT_NOT_ALLOWED`**。

- **限流**：文档未给独立阈值（`application.yml` 只见 `tts-quota.json` 与开关）⇒ **未实现**（按全局 20/分钟理解）。
- **缓存**：磁盘 sha256 缓存（服务端），HTTP 层不缓存。
- **已知坑**：别按"能传任意文本"写代码；`503` 是**设计关闭**，不是故障。

### 示例 3（Python）：带 429 / `Retry-After` 处理的只读轮询（含聚合复用）

```python
#!/usr/bin/env python3
"""只读巡检：/api/public/home.js 一次拿 alerts+geo+honeypot（+audit），
遇到 429 按 Retry-After 退避，不并发、不加 cache-buster。"""
import json, time, urllib.request, urllib.error

BASE = "https://demo.xiaokeqing.cn"
UA = "xk-openapi-example/1.0 (read-only)"

def get(path, tries=3):
    for i in range(tries):
        req = urllib.request.Request(BASE + path, headers={"User-Agent": UA})
        try:
            with urllib.request.urlopen(req, timeout=40) as r:
                return json.loads(r.read().decode("utf-8")), dict(r.headers)
        except urllib.error.HTTPError as e:
            if e.code == 429:                     # 限流：等它说的秒数，别立刻重试
                wait = int(e.headers.get("Retry-After") or 10)
                print(f"429，{wait}s 后再来（第 {i+1} 次）")
                time.sleep(wait)
                continue
            body = e.read().decode("utf-8", "replace")
            raise SystemExit(f"HTTP {e.code}: {body[:200]}")
        except (urllib.error.URLError, TimeoutError) as e:
            print(f"网络错误：{e}（{i+1}/{tries}）")
            time.sleep(5)
    raise SystemExit("三次都没取到 —— 如实报失败，不补样例值")

data, hdr = get("/api/public/home.js")
d = data["data"]

print("缓存年龄 =", d.get("cacheAgeSeconds"), "秒；响应头 Age =", hdr.get("Age"))
a = d["alerts"]
print(f"告警窗口 {a['windowMinutes']}min：rawTotal={a['rawTotal']} → 聚合后 {a['total']} 条")
print("24h 总量 =", a["stats24h"]["total"], a["stats24h"]["bySeverity"])
print("数据源 =", a["dataSource"]["wazuhMode"], "degraded =", a["dataSource"]["degraded"])

g = d["geo"]; c = g["coverage"]
print(f"地理：totalAlerts={c['totalAlerts']} 带源IP={c['withSourceIp']} 定位成功={c['geocoded']} "
      f"排除自身={c['excludedSelf']} 排除内网={c['excludedInternal']}")
print("Top 国家：", [(x["country"], x["count"]) for x in g["byCountry"][:3]])

h = d["honeypot"]
print(f"蜜罐：connections={h['connections']} logins={h['logins']} sampled={h['sampled']}")
if "audit" in d:          # 聚合块在变，出现了才有
    s = d["audit"]["summary"]
    print(f"审计：blockTotal={s['blockTotal']} blockActive={s['blockActive']} "
          f"blockedByGuard={s['blockedByGuard']} executedActions={s['executedActions']}")
else:
    print("审计：本次 home 响应里没有 audit 块（聚合范围在变动）→ 单独取 /api/public/audit.js")
```
