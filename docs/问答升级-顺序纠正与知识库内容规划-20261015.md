## 二、机制划分：什么进知识库（KB）、什么必须走工具

**判据**：变化慢 + 体量小 + 要"解释" → **进 KB** ✓ ｜ 变化快 + 要"精确现值" → **走只读工具** ✗

### A. 该进 KB 的（静态/半静态事实，人工审后入库 ✓）

```
① 站点说明：这站是什么、五页各讲什么、数据从哪来、多久更新、哪些数字是真实只读接口的
② **数据口径**（最重要 ✓）：哪些数字是真的、哪些是演示（现在已清零 ✓）、"取不到就写读不到"的承诺、
   IP 展示规则（前三段+最后一段打码 ✓ 站主已定）、蜜罐凭证只给结构不给明文
③ 隐私与合规：我们记录什么、不记录什么、日志保留口径、为什么不给原始日志
④ 术语表：fail-closed / RAG / 蜜罐 / IDS / 纵深防御 / 误报抑制 / 供应链 …（对应站点文章 ✓）
⑤ **她的设定**：性格、口癖、禁忌、拒绝四步法（`docs/persona.md` 已有 ✓ 可直接作为检索/风格源 ✓）
⑥ 使用说明：怎么用 `/ai/` 页、语音怎么开（为什么有时没声音 ✓ 手势门控）、为什么有时答"没依据"
⑦ 方法论：我们的检测流程、误报处理、演练、发布链与回滚（可从 RUNBOOK 派生，**脱敏** ✓）
⑧ 已有文章正文：10 篇 posts + 分类/标签页内容（**待核对**：现在这 33 篇是否已包含它们 ✗）
⑨ 常见问题 FAQ：由真实高频提问沉淀而成（见 四-③ ✓）
```

### B. 该走只读工具的（实时/精确现值，**不进 KB** ✗）

```
· 当前威胁等级 · 最新告警流 · 24h 计数 · TOP 来源当前榜 · 封禁榜 · 实时故事线
· 任何"现在/今天/最近"的数字 —— 一旦进了 KB 就会**过期说谎** ✗✓
· 8 个现成端点：overview / alerts / alerts/{id} / latest / honeypot / audit / geo / stories（+ kb?q= ✓）
· 硬规则：**凡数字必须带来源与时间** ✓（回答里写清"截至 HH:MM 的接口快照"✓，不许把旧快照当现况 ✗）
```

### C. 半静态（可**派生**进 KB，必须脱敏 + 定期重建 ✓）

```
· 近 7/30 天攻击**统计摘要**（TOP 国家/端口/手法分布 ✓ 由日志聚合生成 ✓ 每次重建带时间戳 ✓）
· 故事线**摘要**（每次事件一句话 ✓ 不含明文/完整 IP ✗）
· 检测能力清单**摘要**（我们覆盖哪些手法 ✓ 不暴露规则细节 ✗）
· 日报/周报里的**数字快照**（可入库，但回答时必须声明"这是 X 时的快照" ✓）
```

## 三、还能放什么（扩展清单，按性价比）

```
① **问答日志 → FAQ 沉淀**（最划算 ✓）：把高频真实提问自动生成候选条目 → 走既有 `kb-pending` 审核流 ✓
   ⇒ 库会自己长起来，而且长的都是**访客真问的东西** ✓（比人工猜题强 ✓）
② **站点数字字典**：把"屏上每个数字的定义/口径/更新时间"写成条目 ✓ → 它就不会把 24h 计数解释错 ✓
③ **文章问答对**：每篇 posts 派生 3~5 条 Q&A（人工审 ✓）⇒ 检索命中率与答案可读性都会上去 ✓
④ **她的语气样本**：persona 之外再放 10~20 条"标准回答范例" ✓ → 回答风格更统一 ✓
⑤ **多语言**（可选）：日语版站点说明（她是日语角色 ✓）—— 但问答语言策略要先定 ✗
⑥ **embedding/分块升级**：embedding 换代、分块从 800/100 做 A/B（**无数字不改** ✗）
⑦ **结构化指标接入**（可选）：日报 CSV/JSON 入库 ⇒ 能答"上周拦截多少"✓（须带时间戳 ✓）
```

**明确不做** ✗：把原始日志行、完整 IP、真实口令明文、内部路径/端点名、规则细节、密钥放进任何语料 ✓

## 四、治理规则（保证库不会变成"说谎源" ✗）

```
① 入库必过审：走既有 `kb-pending` 流程 ✓（现在库里有 33 篇全部 `_source_type=community` 合规 ✓）
② 每条必须带：来源 · 时间戳 · 是否快照（✓ 快照类回答时必须声明时间 ✗）
③ 可回滚：语料以文件形式版本化 ✓（能一键退回上一版 ✓）
④ 定期重建：向量库现在**停在 10-12 15:13** ✗ ⇒ 补"新鲜度与重建流程"（原 L 方案 G 项 ✓ 1 人日）
⑤ 边界：KB 只放"解释与口径"✓；**数字现值一律走工具** ✗
⑥ 评测：对外可引用的数字必须来自**真实访客问题集**（可由日志派生构造 + 脱敏 ✓），
   **不得引用同域自测结论** ✗（这条是对 L 报告的纠正 ✓）
```
