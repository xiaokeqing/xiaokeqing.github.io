XK-LAB // 靶场 TARGET-RANGE ● 本体在 lab.xiaokeqing.cn · 需访问码

Pikachu 漏洞练习平台 · 在线（仅站主可进）

跑在独立的内网网络里：禁出网、单独 IP、512MB / 1 核限额；外面套一道口令门禁， 没有访问码的人只会看到一页 401。

进入靶场 →

里面有什么

Pikachu 自带 15 类、几十个子场景，都是**故意留的洞**：

暴力破解XSSCSRFSQL 注入 RCE文件包含文件下载文件上传 越权目录遍历敏感信息泄露PHP 反序列化 XXEURL 跳转SSRF

为什么别人点不开

  • 公开靶场等于给别人一台免费跳板。放在公网上，扫描器几小时内就会发现它；
  • 就算没被利用，跑洞的流量也会污染我这边的告警统计，让真实攻击淹没在练习流量里；
  • 所以做了口令页：正确访问码 → 种一枚 24 小时的签名 Cookie；错码就是 401，不告诉你差在哪。
边界怎么定的可以查

网络：容器在 labnet（--internal）里，没有默认网关，容器内 wget 外网直接失败；
入口：lab.xiaokeqing.cn → Cloudflare 隧道 → nginx auth_request → 口令服务（只监听 127.0.0.1:8090）；
资源：--memory 512m --cpus 1，挂 unless-stopped，跑挂了也只影响它自己；
隔离：它与博客、API 不在同一网络里，出不了内网，也碰不到别的容器。

$ curl -sI https://lab.xiaokeqing.cn/

你也想练怎么办不用来敲我这台

一行命令在你自己机器上起同款（Docker 装了就行）：

docker run -d --name pikachu -p 8088:80 area39/pikachu:latest
# 然后开 http://127.0.0.1:8088 ，先点页面上的「初始化安装」

如果你只是路过想看效果：这一页已经把能看的部分都写出来了； 真要动手，自己起一台更安全——我这台的访问码不外发。
