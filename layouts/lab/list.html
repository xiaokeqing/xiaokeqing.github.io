七台靶场 · 内网在线（公网入口已撤）

Pikachu:8081

PHP + MySQL，国内教学向，15 类洞都有独立小场景，适合一层层按清单过。

暴力破解XSSCSRFSQL 注入 RCE文件包含文件上传SSRF

DVWA:8082

同类的 PHP 靶场，好处是 难度可调（low → impossible）：同一处洞能在四个级别上对比手工利用与防护差别。

命令注入SQL 盲注反射/存储 XSS 文件包含弱会话CSRF

Juice Shop:8083

现代的 Node 靶场，带一条 100+ 关的闯关计分轨，偏 业务逻辑与前端面，练「这些漏洞串起来能干什么」。

越权注入XXE不安全反序列化 目录遍历评分闯关

WebGoat:8084

OWASP 官方教学式靶场：30+ 节课边讲边练，每节课只讲一个点，适合按顺序补基础。登录 webgoat-user / webgoat。

SQL 注入XSSCSRFXXE JWT/会话访问控制 IDORSSRF反序列化

WebWolf:8087

和 WebGoat 是一套东西，跑在同一个容器里：WebGoat 负责学，WebWolf 负责收 —— 给靶场收邮件、托管你自己写的伪造页面、看外部请求回连到了没有。练「盲打」那类洞（邮件找回、SSRF 回连、XSS 外带数据）没有它就只能干看着。入口 127.0.0.1:8087，账号同 WebGoat webgoat-user / webgoat。

收信服务器伪造邮件SSRF 回连 XSS 外带页面托管请求日志

DVNA:8085

Node/Express 全栈靶场，服务端逻辑占比高，适合看同一套代码里前台与 API 两侧的洞。登录 admin / admin123。

登录 SQL 注入命令注入模板注入 SSTI 任意上传/下载SSRF账号枚举信息泄露

DSVW:8086

单页浓缩型（不到 100 行）：一页列出几十个洞，每条都给 vulnerable / exploit / info 三连链接，适合快速过一遍广度。无认证。

盲注/UNIONXPath 注入登录绕过HPP XSS 三型XXE路径穿越文件包含RCE

为什么不对公网开

  • 公开靶场等于送人一台免费跳板：扫描器几小时内就会找到它；
  • 2026-10-17 我试过用口令页护住 lab.xiaokeqing.cn，第二天云厂商就按「对外暴露高危漏洞站」发了告警；
  • 所以干脆把公网入口整条摘掉，只保留内网 + SSH 隧道，云侧扫不到、也不该扫。

边界怎么定的

网络：容器在 labnet（--internal）里，没有默认网关，容器内 wget 外网直接失败；
入口：nginx 只监听 127.0.0.1:8081~8087，Cloudflare 隧道里已没有 lab 这条 ingress；
资源：各自 --memory 限额 + --cpus 1，挂 unless-stopped，跑挂了只影响它自己。
