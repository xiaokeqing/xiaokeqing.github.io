## 0x01 Vim概述

### 1.1 编辑器种类

vim：编辑器之神

```
nano
```

gedit：只有图形软件可以使用的编辑器等等

### 1.2 vim概述

Vim是从 vi 发展出来的一个文本编辑器。代码补全、编译及错误跳转等方便编程的功能特别丰富，在程序员中被广泛使用，和Emacs并列成为类Unix系统用户最喜欢的文本编辑器。vim软件来源于GNU社区。

Centos等主流linux系统已经内置了vim软件，不需要另行下载。

vim编辑器的前身叫vi编辑器（文档编辑工具，类似于word，记事本）

在开始学习以前，我需要给你们一些警告：

  - - 学习vim在开始时是痛苦的。

  - - 需要时间

  - - 需要不断地练习，就像你学习一个乐器一样。

  - - 不要期望你能在3天内把vim练得比别的编辑器更有效率。

  - - 事实上，你需要1-2周时间的苦练，而不是3天。

## 0x02 Vim使用

### 2.1 编辑文件

### 2.2 vim工作模式

  - 命令模式：复制、粘贴、删除、定位光标、撤销、恢复上一步撤销

## 0x03 末行模式命令

```
：w              保存
：wq             保存并退出
```

：w  文件名       另存为：q！            强制退出：r  文件名       读取别的文件内容到本文件！

```
：set nu         显示文件行号
：set nonu       取消行号
```

：/字符串         从光标所在行往下查找字符串，n下一个，N为上一个：set hls        以高亮形式显示查找字符串：set nohls      取消高亮形式显示查找字符串

```
：%s/old/new/g   将所有行的old替换为new
：2,6s/old/new/g  将第2到第6行的old替换为new
：4,6y           复制4-6行
：4,6d           删除4-6行
```

：g/关键字/d      删除关键字所在的每一行注意：每执行一条命令，都会自动回到命令模式！

## 0x04 命令模式命令

复制粘贴：

yy   复制当前行yw   复制一个单词10yy 一次性复制10行内容p    在光标所在行的下方粘贴定位光标：

G    将光标跳到最后一行

100G 跳到100行

1G或gg 跳到第一行删除字符：

dd   删除当前行10dd 向下删除10行dw   删除一个单词x或delete键    删除光标所在字符ctrl +v 进入区域选择通过左右键进行圈块 后x删除，或者d删除，或者y进行复制区块。撤销：

```
u           撤销
ctrl +r     恢复撤销
```

## 0x05 案例：永久设置别名

alias  别名的建立

```
alias ls='ls --color=auto'
alias cc='ls -l'
source .bashrc 修改生效
unalias ll     取消别名
```

注释：修改自己家目录中 .bashrc的文件 使其永久生效，必须重启重新加载配置文件才能生效！~/.bashrc 某用户自己的别名文件

/etc/bashrc  全局别名文件（再次证明linux的一切皆文件）
