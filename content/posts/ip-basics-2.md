## 二、IP地址

IP地址就是一个唯一标识，是一段网络编码由32位组成192.168.1.1 11000000.10101000.00000001.000000001 255.255.255.0 /24

192.168.1.1（为了方便人类书写和记忆，转换成了十进制）

1                 1             1           1          1          1          1          1 2^7          2^6       2^5        2^4     2^3      2^2      2^1        2^0 128    +     64    +    32    +   16  +    8   +      4   +      2    +     1   =  255 IP地址形式：X.X.X.X     X的范围：0-255   全世界IP范围: 0.0.0.0  -- 255.255.255.255 （ipv4）

  - ipv6:涉及到很多协议、终端接口要换。世界上每一粒沙子都能分配一个IP地址。

  - 进制转化需要他的位权和占位然后乘方运算，位权逢2进1，占位从右边算第0位，所以2^0

  - 如：

```
正确：10.1.1.1 、192.168.1.1
错误：300.1.1.260
```

## 三、子网掩码

子网掩码：subnet mask = SM（划分网段）

局域网通信规则：在同一个局域网中，所有的IP必须在同一网段中才可以互相通信！

```
湖北 .   武汉 .   东西湖.     张三
192.    168.     10.         10
255.   255.      255.         0
湖北 .  武汉  .   东西湖 .    李四
192.    168.     10          20
255.   255.      255.        0
湖北 .   武汉 .   武昌.      王五
192.    168.     20.         10
255.   255.      255.         0
```

  - 练习 调整子网掩码使得以上ip都能通信

IP地址构成：网络位+主机位子网掩码： 用来确定IP地址的网络位子网掩码如何确认网络位：与255或者1对应的数字为网络位，与0对应的数字为主机位255.0.0.0 255.255.0.0 255.255.255.0主机位：不可以全0（网络地址） 不可以全为255（广播地址）       192.168.100.255/255.255.255.0

  - 如：

  - 10.1.1.1 255.0.0.0

获知：10.1.1.1属于10.网段，名字叫.1.1.1        10.0.0.0/255.0.0.0

  - 10.255.255.255/255.0.0.0

获知：10.1.1.1属于10.1.网段，名字叫.1.1    10.1.0.0/255.255.0.0

## 四、IP地址详解

国际标准组织ISO定义地址分类：五大类 （是以IP地址的第一位进行区分的）.A类： 1-126         默认子网掩码：255.0.0.0              10.0.0.0 B类： 128-191     默认子网掩码：255.255.0.0         172.16-172.32 C类： 192-223     默认子网掩码：255.255.255.0     192.168 D类： 224-239     组播地址（普通计算机无法使用）

E类：  240-254     科研使用（普通计算机无法使用）

  - 如：a b c 三类地址都有一组特殊的地址专门供给内网使用

  - 10.1.1.1 属于A类

```
172.16.1.1 属于B类
192.168.1.1 属于C类
224.0.0.5 属于D类
127.0.0.0  127网段指向自己
255.255.255.255 广播地址
```

  - 0.0.0.0

  - 注：

  - 1. 目前我们可以使用的只有A、B、C3类

  - 2. ABC3类的子网掩码可以修改！

  - 3. 255开头得当作子网掩码来使用了

  - 4. 127开头当作回环地址：如127.0.0.1，代表自己

  - 5. 0开头得，欲知后事，请听以后分解！

## 五、网关

网关：一个网络/内网的出口，Gateway=GW，一般网关是在路由器内部接口上路由器：可用连接内外网的设备（路由器专门用来连接不同网段的）·。

  - PC向外发包：

  - 1、首先判断目标IP地址与自己是否在同一网段。(掩码 网段地址)

  - 2、如在同一网段，则直接发出去，而不找网关

  - 3、如不在同一网段，则直接发包给网关

## 八、网络测试命令

1、如何查看IP地址首先：开始--运行--输入cmd--进入命令行窗口      或者win+r打开运行窗口

```
ipconfig                   # 查看IP地址基本信息
ipconfig  /all             # 查看IP地址详细信息
```

2、测试网络连通性

  - ping  目标IP地址            # 测试网络连通性，有去有回即为可以成功通信！

```
ping  -a  目标IP地址        # 获取对方的计算机名
ping  -t  目标IP地址        # 一直ping        ctrl+c 立即终止
ping  -n  数字 目标IP地址    # 修改ping包的数量
ping  -l  数字 目标IP地址    # 修改ping包的大小
```

  - 注：如ping不通，可能对方不在线，或者对方开着防火墙！

3、手工解析域名

```
nslookup  域名
tracert www.baidu.com 查看到该网址经历的节点设备
```
