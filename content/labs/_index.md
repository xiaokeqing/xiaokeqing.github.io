## 为什么做这个页面

安全的东西光看文章是记不住的。**自己动手试一次，胜过读十篇原理。**

所以这里不放"漏洞利用工具"，而是放**可交互的原理解释**——你在浏览器里输入，立刻看到结果和原因。

> **一个重要说明**：这里的演示**全部运行在你自己的浏览器里，没有任何真实漏洞**。
> 你输入的 payload 只会被当作字符串分析，不会被执行，也不会发到任何后端（除明确标注的两项）。

## 换成真实内容时的写法

每个演示建议做成独立页面，目录结构：

```
content/labs/
├── _index.md               ← 本文件（列表页）
├── sql-injection.md        ← SQL 注入演示
├── xss.md                  ← XSS 演示
├── path-traversal.md       ← 路径穿越演示
├── command-injection.md    ← 命令注入演示
└── attack-me.md            ← 试着攻击我（连后端）
```

每个演示页面包含四块：

1. **任务** —— 明确目标（"绕过登录"、"读到 /etc/passwd"）
2. **操作区** —— 输入框 + 提交按钮
3. **结果区** —— 成功/失败 + **后台实际发生了什么**（这是教学重点）
4. **防护对比** —— 一键切换到"已修复版本"，看攻击为什么失效
